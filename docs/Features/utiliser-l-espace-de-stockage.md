# Utiliser l'Espace de stockage

Vous pouvez utiliser Dendreo comme un [Espace de stockage](https://pro.dendreo.com/redirect/documents-sauvegardes) pour votre gestion documentaire, afin d'y archiver les **versions définitives ou signées** de n'importe quel document, directement au sein des différentes fiches (Entreprise, Participant, Action de Formation) du logiciel, pour les **retrouver facilement et les partager avec le reste de votre équipe**.

Au même titre que Dropbox, Google Drive ou One Drive, l'Espace de stockage de Dendreo fonctionne **comme un disque dur** dans lequel vous pouvez **enregistrer, consulter et partager** tous les documents administratifs relatifs à votre activité d'Organisme de Formation. Les documents sont stockés sans **aucune limite de durée** !

Les formats acceptés sont **.jpg, .jpeg, .bmp, .png, .gif, .heic, .heics, .heif, .heifs, .svg, .pdf, .csv, .doc, .docx, .dot, .dotx, .docm, .dotm, .xls, .xlt, .xlsx, .xlsb, .xltx, .xlsm, .xltm, .ppt, .pptx, .ppsx, .zip, .rar, .tar, .gz, .odt, .ods, .odp, .avi, .mov, .qt, .mp4, .mkv, .mp3, .aac, .wma, .ogg, .wav, .m4a, .xml, .pages, .txt, .eml, .msg, .tif, .tiff, .json, .odf, .ggb, .m2ts, .mts, .klx, .pbix, .pub, .zed, .asf, .url, .skp, .layout, .stl, .step, .pln, .dwg, .dwf, .f3d, .f3z, .sldprt,** et **.md**. La taille d'un fichier ne peut pas être **supérieure à 4 Go**.

## Avant-propos

Cette fonctionnalité est une option **incluse par défaut** dans votre abonnement. Sa bonne prise en main implique cependant que vous maitrisiez les fonctionnalités suivantes :

- La [gestion électronique de document par QR Code](https://doc.dendreo.com/article/495-inserer-qr-code) qui facilite le tri et l'archivage des documents ;
- La [signature électronique de documents](https://doc.dendreo.com/category/258-signature-electronique) qui vous permet de faire signer numériquement vos documents administratifs qui seront alors automatiquement stockés sur votre compte Dendreo ;
- Le [partage des documents](https://doc.dendreo.com/article/500-partager-un-document-dans-l-espace-de-stockage-depuis-l-envoi-d-un-email) en pièces jointes depuis l'interface d'envoi des Emails directement vers les Espaces de stockage des destinataires ;
- Les Extranets [Participants](https://doc.dendreo.com/article/220-extranet-participant), [Formateurs](https://doc.dendreo.com/article/48-extranet-formateur-portail) et [Entreprises](https://doc.dendreo.com/article/269-extranet-entreprise) depuis lesquels vos interlocuteurs peuvent accéder aux documents que vous leur aurez partagés.

## Fonctionnalités

Les fonctionnalités principales de l'Espace de stockage sur Dendreo sont les suivantes :

- Un Espace de stockage **sécurisé** par un système de **cryptage des fichiers** ;
- Le **stockage en illimité** de tous vos fichiers sur tous les Espaces de stockage ;
- Une arborescence de dossiers sur **plusieurs niveaux** ;
- Le stockage de vos fichiers par ADF, par interlocuteur (Formateur, Entreprise, Participant) ou par Salle ;
- La personnalisation de l'**arborescence des dossiers** de vos Espaces de stockage ;
- La possibilité de partager des fichiers avec des **interlocuteurs externes** ;
- Des **fichiers indexés** pour les retrouver facilement depuis le moteur de recherche globale ;
- Des dossiers **spécifiques à vos Modules** rattachés à l'espace des ADF composées de Modules ;
- Le [**partage des pièces jointes d'un Email**](https://doc.dendreo.com/article/500-partager-un-document-dans-l-espace-de-stockage-depuis-l-envoi-d-un-email) directement dans les Espaces de stockages correspondants ;
- Le **partage des documents d'une ADF** directement dans les Espaces de stockages correspondants ;
- Des **espaces indépendants** pour les [comptes multi-centres](https://doc.dendreo.com/article/102-la-gestion-multicentres) : l'Espace de stockage peut être configuré pour être **commun à tous les centres**, ou bien indépendant par centre.

## Consulter les Espaces de stockage

Vous retrouvez les Espaces de stockage à différents endroits, selon le contexte de partage du document.

### L'Espace de stockage principal

Disponible depuis le bouton de configuration de votre compte > [***Espace de stockage***](https://pro.dendreo.com/redirect/documents-sauvegardes), cet Espace de stockage vous permet de **conserver des documents administratifs** ou bien de **rendre disponibles ces documents** au niveau de votre structure. Vous y consultez et gérer tous les documents principaux de votre Organisme.

![](https://d33v4339jhl8k0.cloudfront.net/docs/assets/59b2fb88042863033a1cb464/images/6abe1526528fa6f4b198afd5/file-QTPqOIGiPw.png)

Vous disposez d'un dossier partagé avec l'ensemble de vos Entreprises clientes, de vos Participants et Formateurs, toutes Formations confondues. Vos interlocuteurs retrouvent ces documents directement depuis leur [Extranet](https://doc.dendreo.com/article/219-introduction-aux-extranets), dans le menu ***Documents partagés.***

![](https://d33v4339jhl8k0.cloudfront.net/docs/assets/59b2fb88042863033a1cb464/images/6a70a2a2cac3c0576722d8a5/file-ZqIWwbNy6h.png)

Il est possible, sur l'ensemble des Espaces de stockage, de **créer des dossiers** afin de **stocker des documents** ou bien de simplement copier-coller ces documents directement dans cet Espace de stockage. Ceux-ci ne seront pas partagés avec les interlocuteurs cités précédemment, mais consultables et utilisables uniquement en interne par les utilisateurs Dendreo. Vous les retrouvez dans la section ***Mes fichiers***.

![](https://d33v4339jhl8k0.cloudfront.net/docs/assets/59b2fb88042863033a1cb464/images/6ab0e5c990d296d24a91533a/file-ZUWrCVveJN.png)

**Attention** : les dossiers que vous avez créés se suppriment automatiquement s'ils sont laissés vides.

**À noter** : vos utilisateurs qui n'ont pas accès à la configuration de votre Organisme de Formation sur Dendreo retrouvent l'Espace de Stockage principal depuis le bouton de dossier dédié, à la place du bouton donnant accès à la configuration.

![](https://d33v4339jhl8k0.cloudfront.net/docs/assets/59b2fb88042863033a1cb464/images/6ab124f35de3995b2f386288/file-dJPyXnhj4n.png)

### L'Espace de stockage de la fiche Module

Disponible depuis l'onglet ***Espace de stockage*** de la fiche d'un Module, cet Espace de stockage vous permet de déposer des documents tels que les supports pédagogiques à l'attention des Participants ou Formateurs qui ont participé, qui participent ou bien qui vont suivre ce Module.

![](https://d33v4339jhl8k0.cloudfront.net/docs/assets/59b2fb88042863033a1cb464/images/6a70ab36de115eed4366e827/file-k4s0G6h6UY.png)

Vos interlocuteurs retrouvent ces documents sur leur Extranet dans le menu ***Documents partagés*** de l'Action de Formation à laquelle ils participent. Ce qui implique que **toute Action de Formation composée de ce Module peut hériter de ses fichiers**.

[![](https://d33v4339jhl8k0.cloudfront.net/docs/assets/59b2fb88042863033a1cb464/images/6a7c901873778c51e837e428/file-rl5OzoaomG.png)](https://s3.amazonaws.com/helpscout.net/docs/assets/59b2fb88042863033a1cb464/images/6a7c901873778c51e837e428/file-rl5OzoaomG.png)

### L'Espace de stockage de la fiche Action de Formation

Disponible depuis l'onglet ***Espace de stockage*** d'une Action de Formation, vous trouvez dans cet Espace de stockage un **dossier de partage** avec les Entreprises (clientes), les Formateurs dispensant cette Action de Formation et les Participants assistant à cette Formation.

[![](https://d33v4339jhl8k0.cloudfront.net/docs/assets/59b2fb88042863033a1cb464/images/6a7c90473c57d45466b9c98d/file-HQD6tZxCs5.png)](https://s3.amazonaws.com/helpscout.net/docs/assets/59b2fb88042863033a1cb464/images/6a7c90473c57d45466b9c98d/file-HQD6tZxCs5.png)

Le Centre de Formation peut partager des documents avec ces différentes parties prenantes, mais les Participants et Formateurs peuvent aussi rendre disponibles des documents directement depuis leur Extranet.

**À noter** : cela nécessite un paramétrage depuis la [configuration Extranet Formateur](https://pro.dendreo.com/redirect/config/extranet-formateur).

Le dossier ***Signature électronique*** contient l'ensemble des documents qui ont été envoyés avec une demande de [Signature électronique](https://doc.dendreo.com/article/273-introduction-a-la-signature-electronique-de-documents) depuis Dendreo.

[![](https://d33v4339jhl8k0.cloudfront.net/docs/assets/59b2fb88042863033a1cb464/images/6a7c906abdad84857311a723/file-9s6rbcCwGp.png)](https://s3.amazonaws.com/helpscout.net/docs/assets/59b2fb88042863033a1cb464/images/6a7c906abdad84857311a723/file-9s6rbcCwGp.png)

**À noter** : il est indispensable que l'Action de Formation en question soit dans une [étape d'Action de Formation](https://doc.dendreo.com/article/21-etapes-des-actions-de-formation) où l'affichage des documents est visible sur les Extranets.

### L'Espace de stockage des fiches CRM

Retrouvez cet Espace de stockage sur la fiche d'une Entreprise, d'un Formateur, d'un Participant ou encore d'une Salle afin de stocker des documents concernant uniquement cet interlocuteur. Il est possible d'y déposer des documents génériques comme le CV du Formateur, mais également des documents liés à une Action de Formation comme un Contrat de sous-traitance.

Cet Espace de stockage est par ailleurs disponible depuis les Extranets Entreprises, Formateurs et Participants.

[![](https://d33v4339jhl8k0.cloudfront.net/docs/assets/59b2fb88042863033a1cb464/images/6a7c9093714de94e758bac76/file-Z3LynZkCzL.png)](https://s3.amazonaws.com/helpscout.net/docs/assets/59b2fb88042863033a1cb464/images/6a7c9093714de94e758bac76/file-Z3LynZkCzL.png)

Fiche CRM d'un Formateur

### L'Espace de stockage Formateur

Vos Formateurs disposent d'un Espace de stockage accessible depuis leur [Extranet Formateur](https://doc.dendreo.com/article/48-extranet-formateur-portail).

Ils ont deux niveaux d'Espace de stockage :

- Un **Espace de stockage principal** qui permet d'échanger des fichiers uniquement entre votre Centre de Formation et le Formateur. Sur cet espace, votre Formateur dispose d'un dossier lui permettant de partager un fichier avec les autres Formateurs de la Formation ;

[![](https://d33v4339jhl8k0.cloudfront.net/docs/assets/59b2fb88042863033a1cb464/images/6a7c90d573778c51e837e448/file-fjtaazbN4n.png)](https://s3.amazonaws.com/helpscout.net/docs/assets/59b2fb88042863033a1cb464/images/6a7c90d573778c51e837e448/file-fjtaazbN4n.png)

- Un **Espace de stockage par Action de Formation** qui permet de mettre à disposition du Formateur de cette ADF des supports pédagogiques dans un **dossier privé**. Vous pouvez également le faire depuis votre compte Dendreo, en déposant un fichier directement dans l'Espace de stockage du **Module** concerné.

[![](https://d33v4339jhl8k0.cloudfront.net/docs/assets/59b2fb88042863033a1cb464/images/6a7c91013c57d45466b9c99b/file-TqWhNYUDyj.png)](https://s3.amazonaws.com/helpscout.net/docs/assets/59b2fb88042863033a1cb464/images/6a7c91013c57d45466b9c99b/file-TqWhNYUDyj.png)

**À noter** : si vous souhaitez rendre disponible un support pédagogique directement aux **Participants du Module**, le dossier ***Public - Participants*** prévu à cet effet depuis l'**Espace de stockage du Module**.

![](https://d33v4339jhl8k0.cloudfront.net/docs/assets/59b2fb88042863033a1cb464/images/6a7c912fbdad84857311a730/file-im7aDx1Gma.png)

### L'Espace de stockage Participant

Depuis l'[Extranet Participant](https://doc.dendreo.com/article/220-extranet-participant), vous avez la possibilité de transmettre un fichier à un Participant ou bien à l'ensemble des Participants d'une Action de Formation. Le Participant peut également déposer un fichier dans le dossier ***Partagé entre vous et le centre*** depuis son Extranet.

![](https://d33v4339jhl8k0.cloudfront.net/docs/assets/59b2fb88042863033a1cb464/images/6a7c9152714de94e758bac7c/file-CZlzW3gX0d.png)

## Configurer une arborescence par défaut

Depuis la [configuration de la gestion documentaire](https://pro.dendreo.com/redirect/config/fichiers), vous pouvez prédéfinir des dossiers à créer par défaut dans les Espaces de Stockage de vos différentes fiches (Actions de Formation, Formateurs, etc.).

![](https://d33v4339jhl8k0.cloudfront.net/docs/assets/59b2fb88042863033a1cb464/images/670532c98af27b34842bfdcb/file-v9YnggOdMS.png)

**Attention** : concernant les fiches CRM (Formateur, Participant, Entreprise, etc.), l'arborescence ne s'applique pas sur les Espaces de stockage partagés sur les Extranets.

**À noter** : supprimer ou renommer un dossier n'affectera pas les dossiers contenant déjà des fichiers, mais cela affectera tout dossier vide.

## Associer un interlocuteur à un fichier

Depuis l'**Espace de stockage d'une Action de Formation**, vous avez la possibilité d'associer un fichier à la fiche d'un interlocuteur (Entreprise, Particulier, Participant, Formateur, Module) et ainsi **retrouver ce fichier dans leur Espace de stockage respectif**. Pour cela, au survol du fichier, une liste déroulante apparaît, depuis laquelle vous pouvez choisir la fiche à associer.

![](https://d33v4339jhl8k0.cloudfront.net/docs/assets/59b2fb88042863033a1cb464/images/6a7c8ec8bdad84857311a6df/file-4TBW76qonB.png)

Une fois le fichier associé, il apparaît dans l'onglet ***Fichiers liées dans les ADF*** de la fiche CRM de l'interlocuteur.

![](https://d33v4339jhl8k0.cloudfront.net/docs/assets/59b2fb88042863033a1cb464/images/69eb8908b92439566fddc866/file-UTKwwhZB6P.png)

Cependant, sur les Extranets, les fichiers restent présents uniquement dans les dossiers attitrés.

## Partager les pièces jointes d'un Email sur les Espaces

Depuis l'interface d'envoi d'un Email (depuis une Action de Formation ou une fiche CRM), partagez les pièces jointes ***libres*** ou ***générées*** automatiquement par Dendreo directement dans l'**Espace de stockage du destinataire** de l'Email.

[![](https://d33v4339jhl8k0.cloudfront.net/docs/assets/59b2fb88042863033a1cb464/images/649c225574f970393a8b076d/file-nZxPu1ybGV.png)](https://s3.amazonaws.com/helpscout.net/docs/assets/59b2fb88042863033a1cb464/images/649c225574f970393a8b076d/file-nZxPu1ybGV.png)

Pour plus d'informations sur cette fonctionnalité, consultez la documentation [**Partager les pièces jointes d'un Email sur les Espaces de stockage**](https://doc.dendreo.com/article/500-partager-un-document-dans-l-espace-de-stockage-depuis-l-envoi-d-un-email).

## Partager des documents sur l'Extranet depuis une ADF

Depuis une ADF, vous pouvez partager les documents directement sur l'Espace de stockage de l'Extranet d'un Participant. Pour cela, depuis l'onglet ***Documents*** d'une ADF, cliquez sur l'icône violette de partage.

![](https://d33v4339jhl8k0.cloudfront.net/docs/assets/59b2fb88042863033a1cb464/images/65fc3d2744432440552f970c/file-URmFc4EGzF.png)

Choisissez ensuite si vous souhaitez partager le fichier au format word ou PDF.

![](https://d33v4339jhl8k0.cloudfront.net/docs/assets/59b2fb88042863033a1cb464/images/65fc3d57668a210c0c45d7eb/file-8NP0dYE8I4.png)

**Attention** : si l'Action de Formation se trouve dans **une** [**Étape**](https://doc.dendreo.com/article/21-etapes-des-actions-de-formation) **qui ne la rend pas visible sur les Extranets**, le document partagé ne sera réellement consultable que lorsque l'Étape de l'ADF aura évolué.

## Trier automatiquement les documents

La fonctionnalité de reconnaissance de documents avec QR Code vous aide à **trier automatiquement les documents** que vous aurez générés dans Dendreo et que vous souhaitez ré-uploader dans celui-ci. Par exemple des feuilles d'émargement signées, des conventions de Formation qui vous sont retournées signées.

Pour plus d'informations, consultez notre documentation [**Insérer un QR code dans un document**](https://doc.dendreo.com/article/495-inserer-qr-code).

## Déplacer un document

Si vous souhaitez déplacer un document se trouvant dans un dossier vers un autre emplacement, sélectionnez-le puis glissez-le vers le nom de la racine de l'Espace de stockage (dans le gif ci-dessous ***Organisme de Formation + Sous-centres***). Déplacez ensuite le fichier à l'emplacement souhaité.

![](https://d33v4339jhl8k0.cloudfront.net/docs/assets/59b2fb88042863033a1cb464/images/6a709ed03a4e50130e364045/file-wdxKxn3Cmf.gif)

Déplacement d'un fichier du dossier Participants au dossier Formateurs

## Supprimer un document

Pour supprimer un document de l'Espace de stockage (une convention, un contrat, etc.), cliquez simplement sur l'icône de corbeille rouge qui apparaît lorsque vous survolez le document que vous souhaitez supprimer.

![](https://d33v4339jhl8k0.cloudfront.net/docs/assets/59b2fb88042863033a1cb464/images/6a7c8e23997ac821904e2310/file-HkNvmNeETZ.png)

**À noter** : les documents dans la corbeille seront supprimés au bout de 30 jours.

Depuis l'Espace de Stockage, vous pouvez [**supprimer un document signé**](https://doc.dendreo.com/article/276-questions-frequentes).

Pour retrouver et éventuellement restaurer un document supprimé, allez sur l'Espace de Stockage concerné (principal, ADF, fiche CRM) puis allez dans le sous-onglet ***Corbeille*** dans la colonne de gauche.

![](https://d33v4339jhl8k0.cloudfront.net/docs/assets/59b2fb88042863033a1cb464/images/69eb89228e345fb42f2985fd/file-VjIvOnr00m.png)

Retrouvez le document que vous souhaitez restaurer puis cliquez sur l'icône verte ci-dessous.

![](https://d33v4339jhl8k0.cloudfront.net/docs/assets/59b2fb88042863033a1cb464/images/6a7c8e4abdad84857311a6ce/file-8PhzbCFQmj.png)
