# Présentation du BPF

Le Bilan Pédagogique et Financier (BPF) est la déclaration d'activité d'un Organisme de Formation, qui retrace l'ensemble des Actions de Formation réalisées sur une année comptable. Cette déclaration, qui s’effectue exclusivement sur le site [Mon Activité Formation](https://www.monactiviteformation.emploi.gouv.fr/), est une obligation pour tous les Organismes de Formation et doit être transmise au plus tard le **31 mai de chaque année.**

Afin de faciliter la déclaration de votre BPF, une interface dédiée de votre compte Dendreo agrège par année comptable l'ensemble des données liées aux Actions de Formation saisies sur votre compte. De cette façon, lors de la campagne de transmission de votre Bilan Pédagogique et Financier, il vous suffit de reprendre ces données agrégées et les retranscrire sur votre compte du site [Mon Activité Formation](https://www.monactiviteformation.emploi.gouv.fr/).

**Attention** : Dendreo n'agrège pas automatiquement les bonnes données dans les bonnes cases. C'est votre utilisation de Dendreo et la véracité des informations saisies sur votre compte qui font que les données sont correctement agrégées. Ces données sont purement indicatives et leur vérification relève de **votre responsabilité**.

Pour toute question poussée sur le Bilan Pédagogique et Financier, référez-vous au [guide gratuit de Centre Inffo](https://public.dendreo.com/mrsw7zdsmvxv9yldmfsgk6lz/media/gnc239rznbrAwtc24f7g5tcpn8xh4sbypjd2w9swj7zw25kg48Atkk5b4rdf3l5t4r52k6knpjndgrjs48dd285gm26wm76cnq7dsmb5hjffm86djnrAg4lrgq5A2ykggzkx1scl3rww4pj8) ou contactez la Dreets (et obtenez une réponse **écrite**).

## Fonctionnement général

Depuis le menu ***Conformité*** > ***BPF***, accédez à [votre onglet BPF](https://pro.dendreo.com/redirect/bpf_2019.php) agrégeant l'ensemble de votre activité.

![](https://d33v4339jhl8k0.cloudfront.net/docs/assets/59b2fb88042863033a1cb464/images/6ab27a4990d296d24a915812/file-lgMNDqFuJA.png)

Une fois sur l'interface dédiée de votre compte, plusieurs outils sont disponibles :

- **Sélectionner l'exercice comptable**

Dendreo conserve l'historique de votre activité par année comptable. Pour consulter les données agrégées d'une année passée, il convient de sélectionner au préalable **la période souhaitée**.

- **Sélectionner le sous-centre**

Dans le cas où vous vous gérez plusieurs Centres de Formation (= plusieurs SIRET) grâce à l'option de [multi-centres](https://doc.dendreo.com/article/516-presentation-du-multi-centres), Dendreo agrège vos données d'activité **par sous-centre**. Pour consulter les données agrégées d'un sous-centre donné, il convient de le sélectionner dans la liste.

- **Afficher les bulles d'aide**

Si cette option est cochée, Dendreo affiche des encadrés bleus sous chaque partie du BPF afin de vous indiquer les méthodes de calcul appliquées.

[![](https://d33v4339jhl8k0.cloudfront.net/docs/assets/59b2fb88042863033a1cb464/images/65b26ff620e3b82eb738dee7/file-tdwZML3rcO.png)](https://s3.amazonaws.com/helpscout.net/docs/assets/59b2fb88042863033a1cb464/images/65b26ff620e3b82eb738dee7/file-tdwZML3rcO.png)

[![](https://d33v4339jhl8k0.cloudfront.net/docs/assets/59b2fb88042863033a1cb464/images/65b2706620e3b82eb738dee8/file-u3KifnUdKP.png)](https://s3.amazonaws.com/helpscout.net/docs/assets/59b2fb88042863033a1cb464/images/65b26ff620e3b82eb738dee7/file-tdwZML3rcO.pnghttps://s3.amazonaws.com/helpscout.net/docs/assets/59b2fb88042863033a1cb464/images/65b2706620e3b82eb738dee8/file-u3KifnUdKP.png)

- **Afficher les données sources**

Cliquez sur l'icône ci-dessous ***Afficher les données sources*** pour retrouver les sources Dendreo utilisées pour le calcul. Cela vous renverra vers l'export pertinent.

[![](https://d33v4339jhl8k0.cloudfront.net/docs/assets/59b2fb88042863033a1cb464/images/65b26f7252a6af5def3c8c94/file-ocHD6ENmT2.png)](https://s3.amazonaws.com/helpscout.net/docs/assets/59b2fb88042863033a1cb464/images/65b26f7252a6af5def3c8c94/file-ocHD6ENmT2.png)

Vous pourrez y vérifier les informations utilisées, identifier les incohérences le cas échéant pour les corriger dans Dendreo. Vous pouvez télécharger les données sources sous forme de tableur CSV ou XLSX.

**À noter** : pour des exports très volumineux, ce tableau peut devenir très long à s'afficher, vous pouvez alors utiliser les boutons correspondants [pour l'exporter](https://doc.dendreo.com/article/396-les-exports-bpf).

- **Afficher les erreurs**

En sélectionnant cette option, Dendreo affiche en encadré jaune les erreurs identifiées dans la collecte des données du BPF. Vous pouvez alors identifier et corriger les erreurs, en suivant les instructions affichées.

## Limites

- **Dendreo n'alimente pas 100% du Bilan Pédagogique et Financier** : certaines données doivent être collectées en interne auprès de votre Service Comptabilité. Par exemple, dans le cas de vos Formateurs internes, Dendreo ne peut pas calculer le montant exact des salaires bruts, car ceux-ci doivent tenir compte du taux de charges (salariales et patronales) qui peut varier selon plusieurs critères (statut du salarié, nombre d'heures du contrat de travail, etc.).
- **Dendreo ne télé-déclare pas automatiquement votre Bilan Pédagogique et Financier** : bien qu'ayant déjà contacté le service technique du site, il n'existe pas à l'heure actuelle de possibilité de connecter des logiciels externes directement au site gouvernemental.

N'hésitez pas à consulter la [notice explicative détaillée](https://www.formulaires.service-public.fr/gf/getNotice.do?cerfaNotice=50199&cerfaFormulaire=10443) si vous souhaitez en savoir plus sur le BPF.
