# Importer ses données sur Dendreo

Vous venez de vous abonner à Dendreo et vous disposez d'un historique de données relatif à votre activité que vous souhaitez importer dans Dendreo. Dans cet article, nous vous présentons toutes les informations à connaître pour réaliser l'import initial de ces données sur votre compte.

Dans un projet de mise en place de Dendreo au sein de votre Organisme, l'import de vos données est **une étape qui nécessite du temps**. Nous vous recommandons de la prioriser dans votre planning de déploiement.

Téléchargez notre [**masque d'import**](https://public.dendreo.com/mrsw7zdsmvxv9yldmfsgk6lz/media/4jltcsswk8ft14jqg8fxs7sz4vzg57rlpjhh35bq4fgdcqjpn8AhAvtgjjqx4zsggrrw76jqjvrAyqjxl36vAz6kl17hqtkk326xAwj5hjhgyszxnvsgw8l2nb8fqqlqljxdmzrykz6w4pj8). Une fois complété, merci de le retourner à notre équipe [support](mailto:support@dendreo.com).

🎓 Découvrez le masque d'import dans notre [**cours e-learning dédié**](https://academy.dendreo.com/courses/import-initial-de-donnees) !

## Fonctionnement général

Pour vous permettre de retrouver les données nécessaires à la gestion de votre Organisme sur votre compte Dendreo, dans le cadre de la mise en service, nous proposons de réaliser un import initial de vos données.

L'objectif principal de cet import initial est de vous permettre de ne pas avoir besoin de ressaisir manuellement les données de votre CRM, votre Catalogue de Formation et la liste de vos Salles. Vous gagnez ainsi du temps pour prendre en main le logiciel !

Pour réaliser cet import, il convient que vous nous transmettiez les données que vous souhaitez importer en les renseignant dans un **masque d'import** spécialement conçu pour cette prestation. L'utilisation de ce masque d'import est **indispensable** pour garantir que les données à importer respectent bien le **format attendu** par notre base de données.

Une fois que vous avez complété ce masque d'import, il suffit alors de nous le transmettre par email pour qu'il soit validé par notre équipe. Le cas échéant, l'import des données est réalisé par nos soins.

**À noter** : si vous souhaitez supprimer de votre compte les données de démo saisies pendant votre période d'essai de Dendreo, nous vous invitons à contacter notre équipe [support](mailto:support@dendreo.com).

## Procédure d'import des données

Préalablement à l'import de vos données par nos équipes, nous vous recommandons de suivre les étapes détaillées ci-dessous, qui garantissent le bon format des données transmises et vous évitent ainsi de devoir les ressaisir manuellement suite à l'import.

Pendant cette phase de préparation, nos équipes sont disponibles si vous avez des questions.

### Étape #1 - Priorisez les tâches du guide de configuration liées à l'import

Dans le guide de configuration, certaines tâches doivent être réalisées en amont de l'import de données.

Par exemple, dans la [configuration du Catalogue de Formations](https://pro.dendreo.com/redirect/config/modules), vous pouvez définir des **informations par défaut de vos Modules** qui sont **automatiquement renseignées** par Dendreo lors de la création d'une nouvelle fiche Module dans votre Catalogue. Dans le cas de l'import de vos Modules, si des informations spécifiques ne sont pas renseignées pour certains Modules dans le **masque d'import**, lorsque nous importerons la liste des Modules renseignés, chaque fiche Module créée héritera alors automatiquement des valeurs par défaut définies en configuration. En configurant ces informations par défaut avant l'import, vous évitez ainsi de vous retrouver avec des **champs vides**.

Pour identifier les tâches de configuration que nous vous recommandons de réaliser en amont de l'import, ouvrez le guide de configuration directement depuis votre compte Dendreo et activez le filtre dédié aux tâches liées à l'import :

### **Étape #3 - Prenez connaissance de la structure du masque d'import**

Une fois le masque d'import téléchargé, vous devez l'ouvrir avec votre **logiciel Excel**.

Ce fichier est constitué de plusieurs onglets :

- Les onglets ***Instructions*** et ***Contraintes*** vous expliquent comment **renseigner correctement** vos données dans le masque d'import. Nous vous recommandons vivement de les **lire attentivement** avant de renseigner vos données dans les autres onglets.
- Les autres onglets sont prévus pour y renseigner vos données. Chaque onglet correspond à une typologie d'informations à importer : ***Entreprises***, ***Contacts***, ***Participants***, ***Particuliers***, ***Formateurs***, ***Modules***, et ***Salles***.

## **Questions fréquentes**

**Est-ce que l'import initial de mes données est payant ?**

L'import de vos données, réalisé par nos soins, est **inclus dans les frais de mise en service** prévus dans les conditions commerciales de votre abonnement (cf. votre devis) et **doit être réalisé pendant la phase de déploiement**. Si vous souhaitez importer de nouvelles données après la période de déploiement, vous pouvez [importer en autonomie](https://doc.dendreo.com/article/256-introduction-au-crm) une liste d’Entreprises, de Contacts, de Participants et de Particuliers.

**Quelles sont les données que je peux importer ?**

Dans les frais de mise en service indiqués publiquement sur notre [grille de prix](https://www.dendreo.com/prix), seules les données **Entreprises**, **Participants**, **Formateurs**, **Contacts, Particuliers, Modules** et **Salles** sont prévues dans la prestation d'import initial.

Néanmoins, sous certaines conditions, l'**historique de vos Formations (= Actions de Formation mono-module et multi-modules)**, **Créneaux,** **inscriptions, relevés de présence, évaluations** et **Actions Commerciales** peut être importé. Nous vous invitons à vous rapprocher de vos interlocuteurs dédiés chez Dendreo afin de valider la faisabilité technique. Le cas échéant, **notez qu'une participation financière pourra vous être demandée.**

**Est-ce que je peux fournir mes données dans un autre fichier que votre masque d'import ?**

Dans les frais de mise en service indiqués publiquement sur notre [grille de prix](https://www.dendreo.com/prix), vous devez obligatoirement renseigner les données à importer dans notre **masque d'import disponible au format Excel**. Le bon respect du format des données et des contraintes de cette matrice détaillées dans les instructions est indispensable pour que nous puissions réaliser l'import dans ces conditions.

Néanmoins, si vous souhaitez que nous réalisions l'import à partir de données brutes non renseignées dans notre masque d'import, notre équipe reste disponible pour étudier la faisabilité en nous transmettant vos fichiers. Dans ce cas, une participation financière complémentaire aux frais de mise en service vous sera nécessairement demandée.

**Est-il possible de transférer les données hébergées sur un logiciel concurrent de Dendreo ?**

Certains logiciels concurrents de Dendreo peuvent avoir une structure technique relativement proche de la nôtre. Dans ce cas, nous pouvons étudier la possibilité de réaliser un import à partir des fichiers exportés directement depuis le logiciel concurrent. Cette action pouvant faciliter la migration de votre activité vers Dendreo, nous pouvons étudier la faisabilité technique à partir des fichiers que vous nous transmettrez. **Selon la complexité identifiée, une participation financière pourra vous être demandée.**

**Quel est le délai moyen pour faire l'import initial ?**

Dans un projet de déploiement de Dendreo au sein de votre Organisme de Formation, l'import des données est une étape qui prend du temps et dont il ne faut pas négliger le délai de réalisation.

D'expérience, le **délai moyen observé pour que nos clients fournissent les données finales est généralement de 1 mois**. Cette tâche peut s'avérer fastidieuse de votre côté car il peut être compliqué de retrouver vos données et les renseigner manuellement au bon format dans notre masque import.

De plus, il faut compter **un délai supplémentaire de 2 semaines, à compter de la validation par notre équipe**, pour les importer sur votre compte Dendreo lors de la phase de déploiement.

**Est-ce que l'import conserve la mise en forme des contenus renseignés dans le masque d'import ?**

S'il s'agit de champ de texte riche (comme une description ou le contenu d'une fiche Module), vous pouvez conserver la mise en forme en renseignant le contenu avec des balises HTML dans le masque d'import.

**Est-ce que je peux renseigner un champ qui ne figure pas dans la matrice d'import ?**

Oui, il vous suffit pour cela d'ajouter des colonnes. Si une colonne ne se trouve pas dans notre masque d'import mais que le champ existe dans Dendreo, vous pouvez ajouter la colonne dans ce fichier en prenant soin de copier/coller le nom exact du champ, nous l'affecterons correctement. Si une colonne n'existe pas dans ce masque d'import et que le champ n'existe pas dans Dendreo, un champ personnalisé sera automatiquement créé sur votre compte lors de l'import.

**Est-ce que je peux faire plusieurs imports ?**

Non. Dans le cadre de l'import initial réalisé par nos soins, il est **nécessaire de nous fournir toutes les données à importer en une seule fois**, afin d'assurer leur cohérence et d'éviter les doublons.

Dans le cas où vous avez souscrit à un abonnement [multi-centres](https://doc.dendreo.com/article/516-presentation-du-multi-centres) et que vous souhaitez importer des données spécifiques par sous-centre, il faut nous fournir l'ensemble des données dans un fichier unique, en précisant pour chaque donnée à quel(s) sous-centre(s) elle(s) doivent être rattachée(s).

En revanche, pour les imports de données en autonomie, réalisables par vos soins depuis le CRM, vous pouvez réaliser autant d'imports que vous le souhaitez.

**Est-ce que je peux faire l'import de mes données en autonomie ?**

Certaines données peuvent effectivement être importées en autonomie dans le CRM Dendreo, notamment les données relatives aux Entreprises, Contacts, Participants, Particuliers et Inscriptions de Participants dans une Action de Formation. Néanmoins, selon la quantité de données à importer lors de l'import initial, il peut être préférable que celui-ci soit réalisé par nos soins afin de vous faire gagner du temps sur la mise en place de Dendreo au sein de votre Organisme de Formation.

**À noter** : à la suite de l'import initial, vous ne pourrez pas importer de Modules et Formateurs dans Dendreo, ceux-ci devront être créés à la main un par un dans le [Catalogue de Formation](https://doc.dendreo.com/article/74-catalogue-modules-formation-produits-hors-formation) (pour les Modules) et le [CRM](https://doc.dendreo.com/article/61-formateurs) (pour les Formateurs).

Pour plus d'informations sur l'import de données initial, contactez-nous sur [support@dendreo.com](mailto:support@dendreo.com).
