# S'abonner à l'Agenda

Grâce à la fonctionnalité d'abonnement, il vous est possible de visualiser l'Agenda de Dendreo dans votre calendrier préféré (Google Agenda, Outlook, etc.) !

## S'abonner à l'Agenda de Dendreo

Depuis la [configuration de l'Agenda](https://pro.dendreo.com/redirect/config_agenda.php), cliquez sur ***S'abonner à l'Agenda***.

[![](https://d33v4339jhl8k0.cloudfront.net/docs/assets/59b2fb88042863033a1cb464/images/64c90fc78ec1e24edafd20d1/file-rBaZn0uJNh.png)](https://s3.amazonaws.com/helpscout.net/docs/assets/59b2fb88042863033a1cb464/images/64c90fc78ec1e24edafd20d1/file-rBaZn0uJNh.png)

Dendreo vous fournit un lien à utiliser en le copiant/collant dans votre calendrier.

[![](https://d33v4339jhl8k0.cloudfront.net/docs/assets/59b2fb88042863033a1cb464/images/64b93177d48f7f58ce212cbf/file-VCT6QWSiAF.png)](https://s3.amazonaws.com/helpscout.net/docs/assets/59b2fb88042863033a1cb464/images/64b93177d48f7f58ce212cbf/file-VCT6QWSiAF.png)

Le contenu de l'Agenda se met ensuite automatiquement à jour en fonction des modifications faites dans Dendreo. Dans certains cas, il arrive que la fréquence de rafraîchissement atteigne **plusieurs heures**.

**À noter** : cette périodicité dépend de votre logiciel tiers, et est **indépendante de Dendreo**, il ne s'agit donc pas de quelque chose que nous pouvons régler.

### Google Agenda

Pour GA, allez dans ***Paramètres*** > ***Ajouter un Agenda*** > ***À partir de l'URL*** et collez l'URL fournie par Dendreo.

![](https://d33v4339jhl8k0.cloudfront.net/docs/assets/59b2fb88042863033a1cb464/images/64b93227c2f5ed048130c9b0/file-JBfmFw8qfI.png)

### Outlook

Pour Outlook, rendez-vous sur [cette page d'aide](https://support.office.com/fr-fr/article/Importer-un-calendrier-ou-s-y-abonner-dans-Outlook-com-cff1429c-5af6-41ec-a5b4-74f2c278e98c).

![](https://d33v4339jhl8k0.cloudfront.net/docs/assets/59b2fb88042863033a1cb464/images/64b9327778d5c33f492413f0/file-o32RhJy4sw.png)

### Calendrier Apple

Pour Calendrier (Mac OS), rendez-vous dans ***Fichier*** > ***Abonnement à un calendrier***.

![](https://d33v4339jhl8k0.cloudfront.net/docs/assets/59b2fb88042863033a1cb464/images/6184ed569ccf62287e5f35ef/file-qZb4PxHBM4.png)

### Mozilla Thunderbird

Pour Mozilla Thunderbird, rendez-vous dans ***Agenda*** > ***Nouvel agenda sur le réseau***, copiez l'URL fournie par Dendreo dans ***Adresse*** puis recherchez et validez l'abonnement.

![](https://d33v4339jhl8k0.cloudfront.net/docs/assets/59b2fb88042863033a1cb464/images/660bd42d8f8fca7f5efd38a6/file-2txLdRtUdc.png)

Pour plus d'informations, rendez-vous sur l'[aide du logiciel](https://support.mozilla.org/fr/kb/creer-de-nouveaux-agendas).

## Configurer les options

Depuis la [configuration de l'Agenda](https://pro.dendreo.com/redirect/config_agenda.php), paramétrez les options d'affichage dans votre outil calendrier :

[![](https://d33v4339jhl8k0.cloudfront.net/docs/assets/59b2fb88042863033a1cb464/images/64c910558ec1e24edafd20d2/file-wWnA2K1RNW.png)](https://s3.amazonaws.com/helpscout.net/docs/assets/59b2fb88042863033a1cb464/images/64c910558ec1e24edafd20d2/file-wWnA2K1RNW.png)

- ***Afficher les indisponibilités des Formateurs dans les liens d'abonnement iCal*** : afin de choisir si vous souhaitez voir s'afficher ou non les indisponibilités de vos Formateurs dans votre outil de calendrier ;
- ***Fuseau horaire (pour abonnement iCal)*** : afin de définir le fuseau horaire de votre outil calendrier.

**Attention** : si vous téléchargez simplement le fichier .ics en copiant l'adresse dans votre navigateur, puis l'ajoutez par exemple à Outlook en double-cliquant simplement dessus, votre calendrier Dendreo sera simplement figé et copié/collé dans votre logiciel de calendrier, mais ne se synchronisera pas pour l'ajout de nouveaux Événements !

**À noter** : l'abonnement iCal ne permet de récupérer dans le passé que les ADF des 3 derniers mois. Pour les Créneaux futurs, si le nombre de Créneaux à afficher est supérieur à 500, l'abonnement iCal ne récupérera pas plus de 8 mois dans le futur.

## S'abonner à l'Agenda d'un membre de votre CRM

Vous pouvez également trouver des liens d'abonnement individuel pour l'Agenda de chacun de vos Formateurs, Participants, Entreprises et Particuliers sur la page ***Agenda*** de leur fiche. Vous pouvez aussi fournir ces liens individuels à vos utilisateurs pour qu'ils puissent s'abonner à leurs Agendas respectifs.

[![](https://d33v4339jhl8k0.cloudfront.net/docs/assets/59b2fb88042863033a1cb464/images/64c9118e2b0c99358daf17ce/file-uyPzmqPSFQ.png)](https://s3.amazonaws.com/helpscout.net/docs/assets/59b2fb88042863033a1cb464/images/64c9118e2b0c99358daf17ce/file-uyPzmqPSFQ.png)

Bouton d'abonnement à un Agenda Formateur sur Dendreo

Lorsque vous vous abonnez à un Agenda, deux liens s'offrent à vous :

- Le premier pour vous abonner au calendrier de la **vue Administrateur**, la vue visible depuis le CRM qui affiche les Évènements libres et les ADF dont l'Étape permet la visibilité dans les Agendas.

Pour plus d'informations, consultez la documentation [**Créer et gérer les Événements libres**](https://doc.dendreo.com/article/510-creer-et-configurer-un-type-d-evenement-libre).

- Le second pour vous abonner au calendrier de la **vue Extranet**, qui n'affiche que les **Évènements libres publics** et les Actions de Formations dont l'Étape permet la visibilité sur les Extranets.

[![](https://d33v4339jhl8k0.cloudfront.net/docs/assets/59b2fb88042863033a1cb464/images/64f97b44a8b1261bdbc8d3ac/file-DbFcMwn0Wn.png)](https://s3.amazonaws.com/helpscout.net/docs/assets/59b2fb88042863033a1cb464/images/64f97b44a8b1261bdbc8d3ac/file-DbFcMwn0Wn.png)

## Accéder à l'Agenda depuis un smartphone

Dendreo n'a pas d'application iPhone ou Android, vous pouvez cependant synchroniser vos calendriers vous-même entre votre ordinateur et votre téléphone.

Si vous utilisez un compte de calendrier, comme iCloud, Exchange ou Google, vous n'avez pas besoin d'exporter et d'importer le calendrier pour le sauvegarder ou pour l'afficher sur vos autres appareils. Les calendriers de ces comptes sont **stockés** sur les serveurs du fournisseur de service de calendrier et sont **automatiquement** mis à jour sur tous les appareils sur lesquels vous avez configuré les comptes.

## Gérer différents fuseaux horaires

Actuellement, Dendreo ne gère pas les différents fuseaux horaires. Si vous utilisez différents fuseaux horaires dans votre Centre, il vous est possible de gérer cela en créant des sous-Centres.

🗳️ Pour que Dendreo permette de gérer différents fuseaux horaires, n'hésitez pas à **voter pour le développement de** [**cette fonctionnalité**](https://portail.dendreo.com/feedback/68821/) sur **le portail utilisateurs** !

Pour plus d'informations, consultez la documentation [**Je dois programmer une ADF qui se déroule sur un fuseau horaire différent de celui de mon Centre de Formation**](https://doc.dendreo.com/article/508-je-dois-programmer-une-adf-qui-se-deroule-sur-un-fuseau-horaire-different-de-celui-de-mon-centre-de-formation).
