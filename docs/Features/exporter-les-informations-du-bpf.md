# Exporter les informations du BPF

Vous pouvez effectuer plusieurs [exports](https://pro.dendreo.com/redirect/exports) en relation avec votre BPF depuis le menu ***Reporting*** > [***Exports***](https://pro.dendreo.com/redirect/exports).

![](https://d33v4339jhl8k0.cloudfront.net/docs/assets/59b2fb88042863033a1cb464/images/69d8c645800a22d9057312fa/file-6jIvHy9ZGG.png)

Vous pouvez utiliser le tableau présent sur chacune des pages pour **filtrer les informations** qui vous sont nécessaires. Utilisez les outils à votre disposition, tels que la fourchette de date, l'export CSV, l'export Excel, la fonction impression ou encore la fonction recherche :

![](https://d33v4339jhl8k0.cloudfront.net/docs/assets/59b2fb88042863033a1cb464/images/626fc853860c84258681fb43/file-RHa9ZLSywx.png)

**À noter** : par défaut, toutes les colonnes sont affichées ! Sur certains exports, cela peut rendre le tableau peu lisible. Pour limiter le nombre de colonnes affichées, sélectionnez celles que vous souhaitez voir en cliquant sur le bouton ***Colonnes***.
