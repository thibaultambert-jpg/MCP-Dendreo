# Présentation des Exports

Dendreo vous propose plusieurs **Exports globaux automatiques**, disponibles depuis le menu ***Reporting*** > [***Exports***](https://pro.dendreo.com/redirect/exports). Ils reprennent toutes vos données renseignées dans Dendreo et sont calculés automatiquement.

Vous pouvez **filtrer les données** des Exports grâce au sélecteur de dates :

![](https://d33v4339jhl8k0.cloudfront.net/docs/assets/59b2fb88042863033a1cb464/images/69c556e3d700d2211c0c5793/file-mPf41tVZ1b.png)

Deux vues sont disponibles : une vue **en bloc** ainsi qu'une vue **en liste**.

![](https://d33v4339jhl8k0.cloudfront.net/docs/assets/59b2fb88042863033a1cb464/images/69c556f05aab288a1b0b3af2/file-qj5G62EEDS.png)

![](https://d33v4339jhl8k0.cloudfront.net/docs/assets/59b2fb88042863033a1cb464/images/6777f74a9d27044242852588/file-ITRsKxNRCh.png)

Aperçu de la vue en bloc

![](https://d33v4339jhl8k0.cloudfront.net/docs/assets/59b2fb88042863033a1cb464/images/65fbf632881ee906e772696a/file-tXWcYzX4wI.png)

Aperçu de la vue en liste

Une **description** est disponible pour vous aider dans la compréhension de chaque Export.

Si vous cliquez sur ***Exporter***, sélectionnez le format d'export (Excel ou CSV), et indiquez si vous souhaitez être notifié **par Email** lorsque l'Export est prêt, en plus de la notification qui apparaît dans Dendreo.

![](https://d33v4339jhl8k0.cloudfront.net/docs/assets/59b2fb88042863033a1cb464/images/6777f78cd641f0344ea4fd53/file-OweWJxEUFf.png)

Consultez le tableau présent sur chaque Export pour **filtrer les informations** souhaitées, et utilisez les outils disponibles tels que les dates, l'export CSV, l'export Excel, ou les fonctions d'impression et de recherche.

![](https://d33v4339jhl8k0.cloudfront.net/docs/assets/59b2fb88042863033a1cb464/images/65ba6d06a7493b27a932f7e6/file-JDk0vgFSoL.png)

**Attention** : par défaut, toutes les colonnes sont affichées ! Sur certains Exports, cela peut rendre le tableau **peu lisible**. Pour améliorer la lisibilité, sélectionnez les colonnes souhaitées depuis ***Colonnes***.

![](https://d33v4339jhl8k0.cloudfront.net/docs/assets/59b2fb88042863033a1cb464/images/65ba6dac0b2b8f0dacd7f99a/file-ke6Qq5slAI.png)

Il nous est possible de créer des **Exports personnalisés** sur demande, n'hésitez pas à [contacter notre équipe](mailto:support@dendreo.com) afin d'obtenir un devis !
