# Insérer un QR code dans un document

Dendreo simplifie le **tri** et l'**archivage des documents** en utilisant un système de QR Code automatiquement apposé sur tous les documents générés par la plateforme. Il permet à Dendreo de **reconnaître le document**, même après impression, numérisation ou photographie, et de l'**associer automatiquement** aux fiches auxquelles il est lié. Vous pouvez ainsi **identifier et classer facilement vos documents** en toute efficacité.

![](https://d33v4339jhl8k0.cloudfront.net/docs/assets/59b2fb88042863033a1cb464/images/5bfe5ccc2c7d3a31944e7535/file-nhglg5HiU3.jpg)

Un QR code (ou Code QR) a le même fonctionnement qu'un code barre classique mais permet de stocker une plus grande variété et quantité d'informations, et peut se lire dans des orientations différentes.

**Attention** : si vous scannez plusieurs fois votre document comportant un QR code dans des imprimantes différentes ou même trop souvent, la qualité du QR Code se détériore et le QR Code peut ne plus être lisible par Dendreo.

## Activer l'insertion de QR codes

Pour pouvoir utiliser cette fonctionnalité, il faut que votre **niveau d'abonnement à Dendreo le permette**.

Rendez-vous ensuite dans la [**Configuration de la Gestion Électronique de Documents**](https://pro.dendreo.com/redirect/config/fichiers).

Sur cette page, vous pouvez choisir :

- Si vous souhaitez activer l'ajout et la détection des QR Codes sur vos documents générés par Dendreo ;
- La page sur laquelle le QR Code apparaitra si le document est composé de plusieurs pages ;
- La zone d'affichage de QR Code sur cette page.

![](https://d33v4339jhl8k0.cloudfront.net/docs/assets/59b2fb88042863033a1cb464/images/69ef2db6707abf384dcc111f/file-DG0KZMbXZ2.png)

Notez que seuls les documents générés en format natif ou PDF à partir **d'un Modèle au format** ***.docx*** peuvent se voir attribuer un QR Code.

Il est important de définir correctement la position du QR Code sur la page, et de **ne plus la changer**. En effet, Dendreo tentera de reconnaitre vos documents en lisant le QR Code sur la position réglée en configuration. Si vous générez un document avec un QR Code sur une position, que vous changez en configuration, Dendreo peut ne plus reconnaitre automatiquement votre document.

Si vous le souhaitez, vous pouvez désactiver l'ajout du QR code pour un Modèle de Document spécifique. Pour cela, depuis la modification du Modèle, cochez l'icône de QR code barré. Les documents générés à partir de ce Modèle ne comporteront plus le QR code en bas de page.

![](https://d33v4339jhl8k0.cloudfront.net/docs/assets/59b2fb88042863033a1cb464/images/65fbf84744432440552f96cb/file-keNeQeu9wk.png)

## Générer un document avec un QR Code

Une fois l'option activée, tous les documents que vous générerez à partir de Dendreo comporteront un QR code permettant d'identifier facilement ce document lorsque vous le déposerez à nouveau sur Dendreo (depuis l'Accueil ou par Email), et donc le ranger automatiquement dans le bon Espace de Stockage.
