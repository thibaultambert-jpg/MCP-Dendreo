# Présentation du Catalogue de Formation

Le [Catalogue Dendreo](https://pro.dendreo.com/redirect/modules) vous permet de consulter et de créer tous vos Modules de Formation, à partir desquels vous pouvez ensuite organiser vos Actions de Formation INTER ou INTRA.

Ce Catalogue est interne à votre équipe de gestion, mais, si vous utilisez l'option de [Catalogue Public](https://doc.dendreo.com/category/195-catalogue-public), il regroupera aussi des Formations que vous proposez sur votre Catalogue Public à vos visiteurs.

[![](https://d33v4339jhl8k0.cloudfront.net/docs/assets/59b2fb88042863033a1cb464/images/6a8824ee534a1e3b311bedf6/file-5KfYF0XM4y.png)](https://s3.amazonaws.com/helpscout.net/docs/assets/59b2fb88042863033a1cb464/images/6a8824ee534a1e3b311bedf6/file-5KfYF0XM4y.png)

## Pré-requis

Pour le bon fonctionnement de Dendreo, **vous devez créer votre Catalogue de Formation avant de programmer des Actions de Formation**. C'est donc un pré-requis indispensable dans la prise en main de votre compte Dendreo si vous faites vos premiers pas sur le logiciel.

## Fonctionnement général

Sur Dendreo, les Modules sont vos programmes de Formation types dans lesquels vous renseignez les contenus pédagogiques et les informations par défaut que Dendreo utilise lors de la programmation d'Actions de Formation. **C'est l'ensemble de vos Modules qui constitue votre Catalogue de Formations.**

Nous distinguons 2 types de Module :

- Les **Modules synchrones**
- Les **Modules asynchrones (e-learning)**

La distinction entre ces types de Modules se réfère à leur mode d'organisation :

![](https://d33v4339jhl8k0.cloudfront.net/docs/assets/59b2fb88042863033a1cb464/images/68a322962fa97a03213b2ab4/file-wMCI4UXuLt.png)

Choix du mode d'organisation lors de la création du Module

**À noter** : le *Blended* (Formation mélangeant des Créneaux synchrones et asynchrones) n'est pas géré au niveau des Modules mais lors de la planification de la Formation, c'est-à-dire lorsque le Module devient Action de Formation.

## Gérer les Modules de son Catalogue

Depuis votre Catalogue de Formation, vous pouvez :

- Télécharger une archive ZIP des programmes de tous les Modules de votre Catalogue en une seule fois, ou bien téléchargez seulement les programmes des Modules visibles dans le tableau.

![](https://d33v4339jhl8k0.cloudfront.net/docs/assets/59b2fb88042863033a1cb464/images/660d624e11ae3a7defd61384/file-60V0fYTUvc.png)

- Exporter le Catalogue au format Excel ou CSV (en choisissant d'afficher toutes les colonnes ou bien uniquement celles visibles sur le tableau).

![](https://d33v4339jhl8k0.cloudfront.net/docs/assets/59b2fb88042863033a1cb464/images/660d62747e41074545482eb7/file-87Den9CfL5.png)
