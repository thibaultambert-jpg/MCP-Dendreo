# Piloter ses Actions de Formation

Sur le compte Dendreo de votre Organisme, vous pouvez être amené à gérer de nombreuses Actions de Formation. Pour vous aider dans le pilotage de ces Formations, nous avons mis en place un tableau de bord (c'est le cœur du logiciel !), vous permettant de suivre l'avancée de chacune de vos Actions de Formation en un coup d'œil, notamment grâce à **plusieurs éléments visuels**.

Dans cette documentation, découvrez comment utiliser efficacement ce tableau de bord et ainsi piloter plus efficacement l'activité de votre Organisme de Formation en optimisant le suivi de vos ADF 🙌

## Présentation générale

Vous retrouvez toutes vos Actions de Formation depuis le menu ***Formations*** > [***INTER***](https://pro.dendreo.com/redirect/formations/inter?year=2025&etape=toutes) ou [***INTRA***](https://pro.dendreo.com/redirect/formations/intra?year=2025&etape=2).

![](https://d33v4339jhl8k0.cloudfront.net/docs/assets/59b2fb88042863033a1cb464/images/6920832360519c292e93274d/file-pXI6YZRiRq.png)

Si besoin, vous pouvez également accéder à l'interface rassemblant [**toutes vos ADF INTER et INTRA**](https://pro.dendreo.com/redirect/formations/toutes?year=2025).

Vous retrouvez la liste de l'ensemble de vos Actions de Formation INTER ou INTRA sous la forme d'un tableau de bord, ainsi que toutes les informations les concernant organisées dans différentes colonnes.

![](https://d33v4339jhl8k0.cloudfront.net/docs/assets/59b2fb88042863033a1cb464/images/6920832f60519c292e93274e/file-ji8SwxP2p4.png)

## Fonctionnement du tableau de bord

Les informations présentes sur cette interface peuvent être en partie **personnalisées** selon ce que vous souhaitez y faire apparaître (période, Étape, colonnes, etc.), et elles se **mettent à jour en temps réel** selon les modifications apportées sur vos ADF (nombre d'heures, de Participants, Factures émises, Recettes, etc.).

### La période sélectionnée

Pour commencer le pilotage de vos ADF, choisissez la **période** des ADF souhaitées depuis la barre de filtre : vous pouvez afficher toutes les ADF d'**une seule année en particulier**, toutes les ADF **à partir d'une année en particulier** jusqu'à aujourd'hui, ou toutes vos ADF présentes sur Dendreo **depuis la création de votre compte**.

![](https://d33v4339jhl8k0.cloudfront.net/docs/assets/59b2fb88042863033a1cb464/images/6920833632ea624bfc99acd3/file-CyUTk9ayq8.png)

**À noter** : vous pouvez changer le mode d'affichage **par exercice comptable ou par année civile** depuis la [configuration de votre compte](https://pro.dendreo.com/redirect/configuration.php), au champ ***Afficher les Actions de Formation par exercices comptables***. Une ADF à cheval sur deux périodes apparaîtra sur les deux périodes dans cette vue.

Vous pouvez également afficher plus de filtres en cliquant sur l'icône de flèche visible ci-dessus.

![](https://d33v4339jhl8k0.cloudfront.net/docs/assets/59b2fb88042863033a1cb464/images/6920833f60519c292e93274f/file-69GBy9rCtr.png)

### Les Étapes

Par défaut, toutes les Actions de Formation s'affichent dans le tableau, peu importe leur statut d'avancement.

Depuis la colonne de gauche, vous pouvez sélectionner une Étape en particulier pour filtrer la liste des ADF.

![](https://d33v4339jhl8k0.cloudfront.net/docs/assets/59b2fb88042863033a1cb464/images/6920834760519c292e932750/file-8ih6ifqc8h.png)

Pour plus d'informations, consultez notre documentation [**Définir les Étapes d'une Action de Formation**](https://doc.dendreo.com/article/21-etapes-des-actions-de-formation).

### Les colonnes du tableau

Les colonnes du tableau sont entièrement **personnalisables** : vous pouvez ainsi définir les informations dont vous avez le plus besoin dans la gestion quotidienne de vos Actions de Formation.

Cliquez sur le bouton ***Colonnes*** pour afficher toutes les options disponibles et sélectionner celles que vous souhaitez afficher ou masquer dans le tableau de bord. Vous pouvez également vous aider de la barre ***Rechercher une colonne*** pour retrouver plus facilement les options souhaitées dans la liste déroulante.

![](https://d33v4339jhl8k0.cloudfront.net/docs/assets/59b2fb88042863033a1cb464/images/6920835632ea624bfc99acdb/file-417Zkc04CO.gif)

**À noter** : vous ne pouvez pas modifier l'ordre d'affichage des colonnes dans le tableau.

De nombreux indicateurs visuels vous permettent de voir très rapidement les informations recherchées :

![](https://d33v4339jhl8k0.cloudfront.net/docs/assets/59b2fb88042863033a1cb464/images/6920836c9ae59e49c8fa035e/file-TUZ1jJrP3j.png)

Pour plus d'informations, consultez notre documentation [**Comment utiliser les tableaux sur Dendreo ?**](https://doc.dendreo.com/article/717-utiliser-les-tableaux-sur-dendreo).

### Récapitulatif des ADF filtrées

En haut à droite du tableau de bord des Actions de Formation, vous retrouvez un résumé des informations les plus importantes concernant toutes les Actions de Formations du tableau (filtrées selon la période et l'Étape éventuellement sélectionnée). Vous y retrouvez les indicateurs suivants :

- Nombre d'Actions de Formation dans cette Étape ;
- Nombre total de Participants inscrits et non-inscrits ;
- Nombre total d'heures de Formation ;
- Recettes, dépenses et marge totales ;
- Montant total payé, facturé, financé et à financer.

![](https://d33v4339jhl8k0.cloudfront.net/docs/assets/59b2fb88042863033a1cb464/images/6920891d77cc875fb222857d/file-25kwZkHRQx.gif)

**À noter** : ces statistiques représentent **la somme des données affichées dans le tableau de bord**. Elles ne sont pas forcément identiques aux statistiques affichées dans les indicateurs, car une Formation à cheval sur deux années sera affichée et comptée sur chaque année dans le tableau, alors qu'elle ne sera comptée qu'une seule fois dans les indicateurs.

## Exporter le tableau

Vous pouvez exporter le contenu du tableau de bord en cliquant sur ***Export*** > choix du format > ***Exporter***.

L'export peut être fait au format Excel ou CSV. Vous pouvez également choisir d'afficher l'intégralité des colonnes possibles pour ce tableau, ou uniquement les colonnes que vous avez sélectionnées.

![](https://d33v4339jhl8k0.cloudfront.net/docs/assets/59b2fb88042863033a1cb464/images/69208adc4905222bf4662b08/file-n09G8xkfCt.png)

Pour plus d'informations sur les exports, consultez notre documentation [**Présentation des Exports**](https://doc.dendreo.com/article/60-exports).
