# Gérer les droits d'accès à l'Espace de stockage

Les dossiers de l'Espace de stockage étant partagés, il est essentiel que votre Organisme de Formation définisse les droits d'accès des différents interlocuteurs (Formateurs, Participants, Contacts Entreprise) pour qu'ils puissent interagir sur les fichiers stockés et partagés dans celui-ci.

**À noter** : un profil administrateur sur Dendreo est requis pour réaliser la procédure ci-dessous.

Pour configurer ces droits, rendez-vous :

- Dans la configuration des [Extranets Formateurs](https://pro.dendreo.com/redirect/config/extranet-formateur), [Participants](https://pro.dendreo.com/redirect/config/extranet-participant) et [Entreprises](https://pro.dendreo.com/redirect/config/extranet-entreprise) ;
- Dans la rubrique ***Partages de fichiers***, paramétrez les droits de **Lecture** (visualisation, téléchargement des fichiers), d'**Écriture** (dépôt de nouveaux fichiers), d'**Édition** (modification de l'intitulé des fichiers) et de **Suppression** (définitive) des différents dossiers de l'Espace de stockage pour chaque interlocuteur.

*Configuration des droits de l'Espace de stockage de l'Extranet Formateur*

**À noter** : vous ne pouvez pas appliquer ces droits de partage à une personne spécifique.

**Attention** : une précaution toute particulière doit être prise lors de l'attribution des droits de suppression. Si vous accordez aux Formateurs, Participants ou Contacts la possibilité de **supprimer des fichiers** dans un dossier spécifique de l'Espace de Stockage, ils pourront alors supprimer **tous les fichiers présents dans ce dossier**, y compris ceux qu'ils n'ont pas ajoutés eux-mêmes.
