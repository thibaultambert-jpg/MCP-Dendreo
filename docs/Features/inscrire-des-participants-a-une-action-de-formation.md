# Inscrire des Participants à une Action de Formation

Une fois votre Action de Formation programmée, il vous suffit de vous rendre sur la fiche de ladite Action de Formation pour gérer les inscriptions de vos Participants. Il existe plusieurs méthodes pour gérer ces inscriptions selon les informations dont vous disposez concernant les Participants.

Le remplissage d'une Action de Formation se calcule automatiquement en fonction du nombre de Participants inscrits à l'Action de Formation, mais vous pouvez modifier le nombre minimum ou maximum de Participants à inscrire depuis l'interface de création/modification de l'Action de Formation.

**À noter** : actuellement, vous ne pouvez pas inscrire vos Participants par Créneau dans Dendreo : un Participant inscrit à un Module dans une Action de Formation est automatiquement inscrit à tous les Créneaux de ce Module, il vous faudrait alors créer autant de Modules que de Créneaux proposés. Cette évolution est déjà prise en compte par notre équipe Produit : n'hésitez pas à voter pour la [suggestion correspondante](https://portail.dendreo.com/feedback/144310) sur le [Portail utilisateurs](https://doc.dendreo.com/article/464-introduction-au-portail-utilisateur) et à la commenter pour y indiquer votre besoin.

**Méthode #1 - Inscrire manuellement un Participant identifié déjà renseigné dans le CRM**

Depuis l'onglet ***Participants*** de votre Action de Formation, cliquez sur ***Ajouter des Participants***.

[![](https://d33v4339jhl8k0.cloudfront.net/docs/assets/59b2fb88042863033a1cb464/images/6638f260e66450147a8e648b/file-20uFKkiSzR.png)](https://s3.amazonaws.com/helpscout.net/docs/assets/59b2fb88042863033a1cb464/images/6638f260e66450147a8e648b/file-20uFKkiSzR.png)

**À noter** : il n'est pas possible d'ajouter des Particuliers à une INTRA rattachée à une autre Entreprise. Une INTRA ne peut contenir que des Participants de l'Entreprise rattachée ou des [Entreprises du groupe](https://doc.dendreo.com/article/95-groupe-entreprises).

Une fenêtre vous permet de sélectionner les Participants à inscrire à l'Action de Formation :

- Dans la section ***Entreprise (ou Particulier)***, sélectionnez l'Entreprise à laquelle le Participant est rattaché ;
- Dans la section ***Participant identifié***, sélectionnez le Participant à inscrire. Si c'est un Particulier, sélectionnez-le depuis le menu ***Entreprise (ou Particulier)***.

[![](https://d33v4339jhl8k0.cloudfront.net/docs/assets/59b2fb88042863033a1cb464/images/6638f306e66450147a8e648f/file-rRV3T9MIvy.png)](https://s3.amazonaws.com/helpscout.net/docs/assets/59b2fb88042863033a1cb464/images/6638f306e66450147a8e648f/file-rRV3T9MIvy.png)

**À noter** : dans l'onglet ***Participants***, vous retrouvez l'encadré ***Doublons d'inscriptions au Module*** si un Participant est inscrit plusieurs fois au même Module dans plusieurs Actions de Formation différentes (hors ADF annulée ou [recyclage](https://doc.dendreo.com/article/366-les-recyclages)). L'encadré d'alerte ne peut pas être totalement désactivé, mais vous pouvez cliquer sur le nom de l'encadré pour masquer son contenu.

![](https://d33v4339jhl8k0.cloudfront.net/docs/assets/59b2fb88042863033a1cb464/images/68306a31db16bf7fb8f0919e/file-7SYLodIcBd.png)

**Méthode #2 - Inscrire manuellement un Participant identifié non renseigné dans le CRM**

Depuis l'onglet ***Participants*** de votre Action de Formation, cliquez sur ***Ajouter des Participants***.

[![](https://d33v4339jhl8k0.cloudfront.net/docs/assets/59b2fb88042863033a1cb464/images/6638f260e66450147a8e648b/file-20uFKkiSzR.png)](https://s3.amazonaws.com/helpscout.net/docs/assets/59b2fb88042863033a1cb464/images/6638f260e66450147a8e648b/file-20uFKkiSzR.png)

Une fenêtre vous permet de créer les Participants (et leur Entreprise) ou Particuliers à inscrire à l'ADF à la volée.

- Dans la section ***Entreprise (ou Particulier)***, affichez le menu déroulant et cliquez sur ***Nouvelle Entreprise*** ou ***Nouveau Particulier*** pour créer la fiche dans le CRM à la volée sans quitter l'inscription ;
- Dans la section ***Participant identifié***, affichez le menu déroulant des Participants de l'Entreprise sélectionnée précédemment, cliquez sur ***Nouvelle fiche*** puis renseignez les informations du Participant.

[![](https://d33v4339jhl8k0.cloudfront.net/docs/assets/59b2fb88042863033a1cb464/images/6638f8f65ae8353469c6b523/file-06OYmhCmzI.png)](https://s3.amazonaws.com/helpscout.net/docs/assets/59b2fb88042863033a1cb464/images/6638f8f65ae8353469c6b523/file-06OYmhCmzI.png)

**À noter** : cela crée aussi le Participant au sein de votre CRM !

**Méthode #3 - Inscrire manuellement un Participant non identifié**

Dans le cas où vous avez besoin d'inscrire un Participant rattaché à une Entreprise sans connaître encore son identité, Dendreo vous permet d'inscrire un Participant non-identifié comptabilisé alors par Dendreo comme étant un Participant inscrit à l'Action de Formation. Cette solution permet à Dendreo de savoir à quelle Entreprise est rattaché le Participant et vous permettre ainsi de :

- Générer une convention de Formation à l'attention de l'Entreprise ;
- Remplir les relevés de présence ;
- Ajouter des Financements ;
- Émettre des Factures.

**À noter** : tant que l'identité d'un Participant non identifié n'est pas saisie dans Dendreo, vous ne pouvez pas générer de document à destination de ce Participant (attestation, convocation, etc.) renseignez donc ses informations personnelles au préalable.

[![](https://d33v4339jhl8k0.cloudfront.net/docs/assets/59b2fb88042863033a1cb464/images/6639df267303ea4a739d402f/file-DXAHPNnQXk.png)](https://s3.amazonaws.com/helpscout.net/docs/assets/59b2fb88042863033a1cb464/images/6639df267303ea4a739d402f/file-DXAHPNnQXk.png)

**Attention** : un Particulier ne peut pas être ajouté en tant que Participant non identifié.

**Méthode #4 - Inscrire des Participants depuis un import**

Vous pouvez importer en autonomie une liste de Participants depuis l'onglet ***Import*** d'une ADF :

- Dans le cas des INTRA, vous pouvez importer une [**liste de Participants d'une même Entreprise**](https://doc.dendreo.com/article/253-importer-des-participants-en-autonomie-masse-bulk).
- Dans le cas des INTER (ou d'une INTRA Groupe), vous pouvez importer une [**liste de Participants cross Entreprises**](https://doc.dendreo.com/article/302-import-des-participants-cross-entreprises) et réaliser un seul import de Participants qui seront rattachés à plusieurs Entreprises.

**À noter** : un Participant peut être créé depuis l'interface d'import du CRM, et peut être créé ET inscrit depuis l'interface d'import d'une ADF.

[![](https://d33v4339jhl8k0.cloudfront.net/docs/assets/59b2fb88042863033a1cb464/images/6639e0475ae8353469c6b5a9/file-OBiGEvPLhU.png)](https://s3.amazonaws.com/helpscout.net/docs/assets/59b2fb88042863033a1cb464/images/6639e0475ae8353469c6b5a9/file-OBiGEvPLhU.png)

Si vous désirez inscrire un Participant dans une ADF ayant déjà débuté, une alerte vous en informe :

![](https://d33v4339jhl8k0.cloudfront.net/docs/assets/59b2fb88042863033a1cb464/images/6639e0e8e7511e33f36eaecf/file-A3kWUFLCWB.png)

**À noter** : l'Entreprise précisée dans le tableau ***Participants*** d'une ADF est l'Entreprise dans laquelle était le Participant **au moment de son inscription**. Elle peut donc différer de son Entreprise actuelle. Vous pouvez ajouter la colonne ***Entreprise (actuelle)*** en cliquant sur ***Colonnes***.

## Prévisualiser l'Extranet du Participant

Sur chaque Action de Formation où un Participant est inscrit, il est possible de prévisualiser son Extranet Participant. Cela permet notamment de retrouver un certain nombre d'informations liées à cette ADF.

Dans l'onglet ***Extranets*** de l'ADF, cliquez sur le code personnel du Participant pour accéder à son Extranet.

![](https://d33v4339jhl8k0.cloudfront.net/docs/assets/59b2fb88042863033a1cb464/images/6639e4461bee2d183948cade/file-G3DenOnoqd.png)

Si le nom d'un Participant est barré dans une ADF, sa fiche a alors été désactivée dans votre CRM.

Pour plus d'informations, consultez notre documentation [**Présentation de l'Extranet Participant**](https://doc.dendreo.com/article/220-extranet-participant).
