# Définir les Étapes d'une Action de Formation

Depuis la [liste de vos Actions de Formation](https://pro.dendreo.com/redirect/formations/inter) INTER et INTRA, vous retrouvez vos ADF classées dans différentes **Étapes et sous-étapes** qui ont pour but de vous aider à les ranger en fonction de leur **statut d'avancement**, et définir certains comportements automatiques en fonction de ces statuts.

Si vous rencontrez un problème de visibilité de votre Action de Formation, que ce soit sur l'Agenda, votre Catalogue Public ou bien sur les Extranets, cela vient probablement de l'Étape de l'Action de Formation !

![](https://d33v4339jhl8k0.cloudfront.net/docs/assets/59b2fb88042863033a1cb464/images/67e2bc405614b9056b99a687/file-hYeNol3onl.png)

**À noter** : l'Étape d'une Action de Formation ne peut pas se mettre à jour automatiquement et changer d'Étape toute seule, seule une action manuelle de votre part permet de modifier une Étape.

## Configurer les Étapes

Depuis ***Configuration*** > ***Général*** > ***Actions de Formation*** > [***Étapes***](https://pro.dendreo.com/redirect/config/etapes), configurez et personnalisez vos Étapes et leur visibilité afin qu'elles s'adaptent à votre processus administratif interne.

![](https://d33v4339jhl8k0.cloudfront.net/docs/assets/59b2fb88042863033a1cb464/images/67e6a7a8c43e86258f6f9752/file-qrZRi8kDZP.png)

**Attention** : certains paramètres de configuration **affectent votre BPF**, vos indicateurs, votre Agenda, la détection de conflits, le Catalogue Public et les accès Extranets des Formateurs, Participants et Entreprises. Lisez attentivement les points ci-dessous !

- **Créer les Étapes nécessaires**

Cliquez sur ***Ajouter une Étape INTER/INTRA*** pour créer toutes les Étapes nécessaires à votre gestion des Actions de Formation. Par défaut, plusieurs Étapes sont déjà disponibles sur votre compte Dendreo et ne peuvent être supprimées.

![](https://d33v4339jhl8k0.cloudfront.net/docs/assets/59b2fb88042863033a1cb464/images/67e6a7b35cad390a94c043f5/file-vD4QlmWMrh.png)

- **Définir les Étapes favorites**

Définissez l'Étape sur laquelle vous souhaitez que l'onglet ***Formation*** s'ouvre automatiquement en cliquant sur l'étoile. Cela vous permet d'accéder plus rapidement à l'information la plus importante.

![](https://d33v4339jhl8k0.cloudfront.net/docs/assets/59b2fb88042863033a1cb464/images/67e6a7ea6659e6583855f773/file-PWIlTRQsEs.png)

**À noter** : chaque utilisateur de votre compte Dendreo peut paramétrer son Étape favorite, son paramètre prendra alors le dessus sur le paramètre général.

- **Définir l'Étape par défaut**

Cochez la case correspondante pour définir l'Étape que vous souhaitez voir **assignée par défaut** lorsque vous programmez une nouvelle Action de Formation.

![](https://d33v4339jhl8k0.cloudfront.net/docs/assets/59b2fb88042863033a1cb464/images/67e6a7fda57d2d46d41084f9/file-Q4NQLQE7hS.png)

- **Sélectionner un pictogramme d'illustration**

Cliquez sur l'icône correspondante pour sélectionner un symbole visuel qui apparaitra ensuite dans la liste de vos Actions de Formation.

![](https://d33v4339jhl8k0.cloudfront.net/docs/assets/59b2fb88042863033a1cb464/images/67e6a812a57d2d46d41084fa/file-nHMnMZ5OCT.png)

![](https://d33v4339jhl8k0.cloudfront.net/docs/assets/59b2fb88042863033a1cb464/images/67e6a830a57d2d46d41084fd/file-IU9OxaRd39.png)

- **Ordonner les Étapes**

Modifiez l'ordre de vos Étapes et créez éventuellement des sous-étapes en glissant/déposant la ligne sélectionnée au niveau souhaité.

![](https://d33v4339jhl8k0.cloudfront.net/docs/assets/59b2fb88042863033a1cb464/images/67e6a90e5cad390a94c043fb/file-yV6k3CN4wI.gif)

- **Affecter une couleur**

Pour chaque Étape, choisissez la couleur appliquée dans l'Agenda pour toutes les ADF de cette Étape.

![](https://d33v4339jhl8k0.cloudfront.net/docs/assets/59b2fb88042863033a1cb464/images/67e6a9556659e6583855f77e/file-cmih78pEdv.png)

Si vous ne définissez pas de couleur pour une Étape, Dendreo applique une couleur aléatoire régénérée à chaque rechargement de la page. Définissez une couleur spécifique sur chaque Étape pour les Actions de Formation INTER et INTRA pour que la couleur ne change pas.

**À noter** : ce paramétrage fonctionne sous réserve d'avoir [configuré votre Agenda](https://doc.dendreo.com/article/42-configuration-agenda) pour que s'affichent les couleurs de vos Actions de Formation.

- **Définir si les ADF sont confirmées/non confirmées/annulées**

Définissez pour chaque Étape le statut ***confirmée***, ***non confirmée*** ou ***annulée***.

![](https://d33v4339jhl8k0.cloudfront.net/docs/assets/59b2fb88042863033a1cb464/images/67e6a96c6659e6583855f77f/file-kDtzMS8cjR.png)

Les Actions de Formation rangées dans une Étape ***confirmée*** sont prises en compte dans le calcul de vos [Indicateurs](https://pro.dendreo.com/redirect/tdb.php) et dans le [Bilan Pédagogique et Financier](https://doc.dendreo.com/article/31-introduction-au-bilan-pedagogique-et-financier). Le statut ***non confirmé*** est parfois pris en compte dans le calcul de certains indicateurs prévisionnels. Les étapes ***annulées*** ne sont jamais prises en compte, y compris pour la détection de conflits.

- **Rendre visibles ou non les Actions de Formation dans l'Agenda**

Définissez pour chaque Étape la visibilité des Actions de Formation dans l'Agenda.

![](https://d33v4339jhl8k0.cloudfront.net/docs/assets/59b2fb88042863033a1cb464/images/67e6a980c43e86258f6f975e/file-tvCAklNc6O.png)

Les Actions de Formation contenues dans une étape configurée comme étant visible dans l'Agenda seront alors visibles par tous les administrateurs de votre compte Dendreo depuis l'Agenda calendrier et l'Agenda liste (et l'abonnement iCal de l'Agenda du Centre).

- **Rendre visibles ou non les Actions de Formation sur le Catalogue Public**

Définissez pour chaque Étape la visibilité des Actions de Formation sur le Catalogue Public.

![](https://d33v4339jhl8k0.cloudfront.net/docs/assets/59b2fb88042863033a1cb464/images/67e6a9898ad14d24e502e3b3/file-kxF215tOvX.png)

Les ADF rangées dans une étape configurée comme étant visible sur le Catalogue Public seront visibles sur votre Catalogue Public sauf paramétrages contraires au niveau du Module et de l'ADF.

Pour plus d'informations, consultez notre documentation [**Fonctionnement du Catalogue Public**](https://doc.dendreo.com/article/193-fonctionnement-du-catalogue-public-pour-les-participants).

- **Rendre visibles ou non les Actions de Formation sur les Extranets**

Définissez pour chaque Étape la visibilité des Actions de Formation par les Formateurs, les Participants et les Entreprises depuis leur Extranet. Vous pouvez ainsi définir cette visibilité **par Extranet**.

![](https://d33v4339jhl8k0.cloudfront.net/docs/assets/59b2fb88042863033a1cb464/images/67e6a9955cad390a94c043fc/file-xPdCa64oty.png)

Les Actions de Formation seront alors visibles dans leur Agenda ainsi que dans la liste des Formations passées et futures. Ce réglage affecte aussi les abonnements Agenda (iCal) de ces entités.

**À noter** : pour une Entreprise sous-traitante, les Actions de Formation visibles dans le tableau des interventions sont les mêmes que sur l'Extranet Formateur.

**À noter** : le nom de vos Étapes n'est pas visible sur les Extranets. Les Formateurs, Participants, Entreprises n'ont comme seule information le **statut de l'Étape** (***confirmée***, ***non confirmée*** ou ***annulée***).

- **Définir une alerte**

Réglez une alerte en nombre de jours, pour que Dendreo vous avertisse automatiquement lorsqu'une Action de Formation est positionnée sur cette Étape depuis une durée supérieure à ce que vous avez indiqué.

![](https://d33v4339jhl8k0.cloudfront.net/docs/assets/59b2fb88042863033a1cb464/images/67e6a9a36659e6583855f781/file-OsdP0LablA.png)

- **Supprimer une Étape**

Cliquez sur l'icône de corbeille pour supprimer une Étape.

![](https://d33v4339jhl8k0.cloudfront.net/docs/assets/59b2fb88042863033a1cb464/images/67e6a9b05cad390a94c043fe/file-EL5dvSBe1F.png)

**À noter** : vous ne pouvez supprimer que les Étapes que vous avez créées, les Étapes disponibles par défaut sur votre compte ne peuvent pas être supprimées.

## Modifier l'Étape d'une Action de Formation

Depuis l'onglet ***Résumé*** de la fiche d'une ADF, vous pouvez changer son Étape depuis le menu déroulant :

![](https://d33v4339jhl8k0.cloudfront.net/docs/assets/59b2fb88042863033a1cb464/images/662fb31be66450147a8e5f01/file-hhRn36251u.png)

Depuis la liste des Actions de Formation, glissez/déposez une ADF vers une Étape directement dans le menu :

![](https://d33v4339jhl8k0.cloudfront.net/docs/assets/59b2fb88042863033a1cb464/images/662fb3f71bee2d183948c4ff/file-Gb4fwf1Kgl.gif)

**À noter** : une Étape s'applique pour toute l'ADF, pas pour certains Participants ou Modules spécifiques.
