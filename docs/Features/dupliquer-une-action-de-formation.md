# Dupliquer une Action de Formation

Dans certains cas, plutôt que de programmer une nouvelle Action de Formation (INTER ou INTRA), il peut être plus simple d'en **dupliquer** une déjà existante. Cette page vous détaille la procédure à suivre.

**À noter** : la duplication génère un nouveau numéro dédié à l'Action de Formation.

- Sur la page de l'Action de Formation à dupliquer, cliquez sur ***Dupliquer***.

![](https://d33v4339jhl8k0.cloudfront.net/docs/assets/59b2fb88042863033a1cb464/images/662f93351bee2d183948c4d7/file-KRGuW34EXp.png)

- Définissez la date de début de la nouvelle ADF, ainsi que son intitulé (si vous souhaitez le modifier).

![](https://d33v4339jhl8k0.cloudfront.net/docs/assets/59b2fb88042863033a1cb464/images/662f93847303ea4a739d3a61/file-4DINv7rhY6.png)

**À noter** : une fois la duplication terminée, si Dendreo vous signale un conflit de date, vous pourrez modifier les Créneaux par la suite. Pour en savoir plus, consultez notre documentation [**Définir le planning d'une Action de Formation**](https://doc.dendreo.com/article/41-agenda-et-creneaux-des-actions-de-formation).

- Choisissez les éléments à conserver par rapport à l'Action de Formation initiale.

![](https://d33v4339jhl8k0.cloudfront.net/docs/assets/59b2fb88042863033a1cb464/images/662f941de66450147a8e5ed5/file-ZMLl7G1dLp.png)

- Cliquez sur ***Dupliquer cette Formation***.

**Attention** : les lignes de Budget seront également dupliquées, mais si vous avez changé le prix de vos Modules (par rapport à leur prix par défaut), ou si vous avez défini des prix personnalisés par Participants, ceux-ci seront réinitialisés. Toutes les to-dos, checklists, présences, etc. ne sont également pas dupliquées.
