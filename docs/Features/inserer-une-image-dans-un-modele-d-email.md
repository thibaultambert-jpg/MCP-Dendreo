# Insérer une image dans un Modèle d'Email

Cette documentation vous explique comment intégrer une image dans un Modèle d'Email.

**Attention** : ne **déposez pas votre image** directement dans le champ texte ***Corps du mail***.

Depuis la page de [configuration de votre Modèle d'Email](https://pro.dendreo.com/redirect/config_modeles_mails_types.php), dans ***Corps du mail***, cliquez sur l'icône d'image.

![](https://d33v4339jhl8k0.cloudfront.net/docs/assets/59b2fb88042863033a1cb464/images/6a71fe32b169db7cd0b4aa9a/file-Ij5ltVGC2c.png)

Ici, deux solutions s'offrent à vous :

**Solution #1 - Télécharger l'image**

Si l'image que vous souhaitez insérer dans votre Modèle d'Email est déjà sur votre poste, cliquez sur l'onglet ***Télécharger*** puis déposez l'image dans l'encadré. Vous pouvez également cliquer sur ***Rechercher une image***.

![](https://d33v4339jhl8k0.cloudfront.net/docs/assets/59b2fb88042863033a1cb464/images/6a71fe84641871eb1294dd89/file-x4UPQxZuc2.png)

**Solution #2 - Insérer le lien d'hébergement de l'image**

Votre image peut être hébergée sur les serveurs de votre site Internet ou encore sur l'[Espace de Stockage](https://doc.dendreo.com/article/165-espace-de-stockage).

Dans l'onglet ***Général*** de la fenêtre, indiquez dans le champ ***Source*** le **lien d'hébergement de l'image** que vous souhaitez insérer dans votre Modèle.

![](https://d33v4339jhl8k0.cloudfront.net/docs/assets/59b2fb88042863033a1cb464/images/6a71feb8d2264cef31e62f47/file-3TKPvzi2AU.png)

**À noter** : si votre image est hébergée sur l'Espace de stockage de votre compte Dendreo, une URL publique est **automatiquement générée** pour l'ensemble des fichiers stockés. Récupérez l'URL de l'image en cliquant sur l'icône de lien.

![](https://d33v4339jhl8k0.cloudfront.net/docs/assets/59b2fb88042863033a1cb464/images/6a71ff3b641871eb1294dd8d/file-GjVsM7J3YT.png)
