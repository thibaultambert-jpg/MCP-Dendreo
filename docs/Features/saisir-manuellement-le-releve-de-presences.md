# Saisir manuellement le Relevé de présences

Si vous utilisez les [émargements électroniques](https://doc.dendreo.com/article/226-introduction-a-la-signature-electronique-emargements), le Relevé des présences est automatique. Vous le retrouvez dans l'onglet ***Invitations & Présences*** de vos Actions de Formation. Cette interface a été conçue afin de faciliter la gestion de la présence ou absence de vos Participants à chacun des Créneaux de vos ADF.

Elle vous permet d'interagir dynamiquement sur deux tableaux : un premier tableau listant les **Participants inscrits** à votre ADF, un second tableau listant les **Créneaux**, classés par dates.

![](https://d33v4339jhl8k0.cloudfront.net/docs/assets/59b2fb88042863033a1cb464/images/680b8fc4b025d21dcb1e8ed5/file-cVTdsLKNrG.png)

**Attention** : le remplissage correct des présences est obligatoire pour un [Bilan Pédagogique et Financier](https://doc.dendreo.com/article/31-introduction-au-bilan-pedagogique-et-financier) correct et l'envoi du [Questionnaire de Satisfaction](https://doc.dendreo.com/article/240-presentation-du-questionnaire-de-satisfaction).

## Saisir les présences par Participant

Si vous souhaitez marquer les présences par Participant, rendez-vous sur le tableau de gauche : sélectionnez le Participant concerné puis, sur le tableau de droite, cliquez sur le bouton de présence ou d'absence.

![](https://d33v4339jhl8k0.cloudfront.net/docs/assets/59b2fb88042863033a1cb464/images/664366f60aaf8a27e593c16d/file-GfIQF5C8Fr.gif)

**À noter** : il n'est pas possible de renseigner des présences sur un Créneau qui n'a pas encore débuté, vous pouvez cependant enregistrer les absences avant le début d'un Créneau.

Vous pouvez simplement recliquer sur la présence (en vert) ou l'absence (en rouge) pour annuler la saisie.

L'absence peut être injustifiée ou justifiée, avec un motif. Pour une Formation synchrone, vous pouvez indiquer un temps de présence par Créneau, par exemple si le Participant est arrivé en retard, en utilisant le curseur.

![](https://d33v4339jhl8k0.cloudfront.net/docs/assets/59b2fb88042863033a1cb464/images/664367b37987cf7a43f635db/file-O8QOBFzd4L.gif)

**À noter** : si vous envoyez un mail au Participant depuis Dendreo pour lui demander de justifier son absence, cette justification ne sera pas automatiquement intégrée dans le champ ***Commentaire*** au niveau de l'absence ci-dessus, il vous faudra l'ajouter vous-même.

Vous pouvez également cliquer sur ***Marquer présent à tous les Créneaux commencés*** pour le Participant.

![](https://d33v4339jhl8k0.cloudfront.net/docs/assets/59b2fb88042863033a1cb464/images/6644a4a77987cf7a43f636e5/file-1Z6ewT0QuO.png)

**À noter** : si un Participant n'est pas inscrit sur un Module, il ne vous sera pas possible de l'indiquer comme présent sur les Créneaux de ce Module.

## Saisir les présences par Créneau

Pour marquer les présences par Créneau, rendez-vous sur le tableau de droite : sélectionnez le Créneau souhaité puis, sur le tableau de gauche, cliquez sur le bouton de présence/absence pour chaque Participant.

![](https://d33v4339jhl8k0.cloudfront.net/docs/assets/59b2fb88042863033a1cb464/images/6643686b7987cf7a43f635dd/file-qznUmTK6x8.gif)

Vous pouvez également cliquer sur ***Marquer tous les Participants présents*** pour le Créneau.

![](https://d33v4339jhl8k0.cloudfront.net/docs/assets/59b2fb88042863033a1cb464/images/664369f30aaf8a27e593c171/file-djScAHYO2K.png)

## Saisir les présences pour tous les Participants et Créneaux

Vous pouvez aussi marquer **tous les Participants présents à tous les Créneaux** en une seule fois.

![](https://d33v4339jhl8k0.cloudfront.net/docs/assets/59b2fb88042863033a1cb464/images/66436aa203646f27f5ad4871/file-TAy50Sx36o.png)
