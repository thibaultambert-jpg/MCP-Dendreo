# Créer une nouvelle Salle de Formation

Sur cette page, vous découvrirez comment ajouter une Salle pour votre Action de Formation, modifier les informations de celle-ci ou la supprimer, et consulter l'historique des Créneaux ayant eu lieu dans celle Salle.

## Ajouter une Salle

Il existe différentes manières d'ajouter une Salle sur votre compte Dendreo :

- Depuis la liste des Salles (menu ***CRM*** > [***Salles***](https://pro.dendreo.com/redirect/salles-de-formation)) : cliquez sur ***Ajouter une Salle***.

![](https://d33v4339jhl8k0.cloudfront.net/docs/assets/59b2fb88042863033a1cb464/images/6a451f38339a9b5fdc9d29ff/file-Pnle8kY7M5.png)

C'est depuis ce menu que vous retrouvez toutes vos Salles. Pour en consulter une, cliquez sur son nom.

- Depuis le menu ***Lieux (Salles)*** d'une Action de Formation : cliquez sur la loupe puis sur ***Nouvelle fiche***.

![](https://d33v4339jhl8k0.cloudfront.net/docs/assets/59b2fb88042863033a1cb464/images/6814d92b2a2d4a5eb352838b/file-zFlWix9vKP.png)

## Compléter la fiche d'une Salle

Lors de la création d'une Salle depuis la liste des Salles ou depuis une ADF, il est indispensable de définir l'***Emplacement géographique*** de celle-ci. Il permet de définir le type de Salle, à savoir :

- ***Interne*** (au sein d'un de vos Centres de Formation) : pour les Salles de Formations présentielles situées dans les locaux de votre Centre de Formation. Les Salles héritent automatiquement de l'adresse postale de votre Centre, renseignée en [configuration générale](https://pro.dendreo.com/redirect/configuration.php) ;
- ***Externe*** (adresse libre) : pour les Salles de Formations présentielles qui ne sont pas situées dans votre Centre de Formation ou chez un Client. Il faut alors renseigner manuellement l'adresse postale ;
- ***Virtuelle*** (visio, classe virtuelle, etc.) : pour les Salles de Formations à distance. Elles peuvent être configurées pour utiliser [Dendreo Live](https://doc.dendreo.com/article/281-dendreo-live) ou pour des solutions externes de visioconférence (Dokeos, Zoom, Teams, Google Meet, etc.). Pour ce type de Salle, vous pouvez renseigner le lien de connexion depuis :
  - Une URL de connexion par défaut si le lien de connexion est permanent pour toutes vos ADF (dans le cas contraire laisser le champ vide) ;
  - Une URL de connexion personnalisée à renseigner pour chaque Créneau de chaque ADF.
- ***Chez le Client / Sous-traitant*** (2 possibilités) :
  - Pour les Salles de Formations présentielles situées géographiquement dans l'Entreprise. Ces Salles héritent automatiquement de l'adresse postale de l'Entreprise renseignée sur la fiche CRM ;
  - Pour les Salles de Formations présentielles situées géographiquement dans des bureaux de l'Entreprise, mais à une autre adresse que celle renseignée sur la fiche CRM. Il faut alors renseigner manuellement l'adresse postale.

![](https://d33v4339jhl8k0.cloudfront.net/docs/assets/59b2fb88042863033a1cb464/images/689461cecc94a96f86d43c75/file-7M1PB3ZbEL.png)

**À noter** : lors de la création d'une Salle, si vous ne complétez pas ***Accès Handicapés ?***, ***Précisions sur l'accès handicapé***, ***Informations pratiques d'accès*** et ***Informations d'accueil***, votre Salle héritera des informations renseignées dans ***Localisation du Centre de Formation*** de la [configuration générale](https://pro.dendreo.com/redirect/configuration.php).

**À noter** : toute modification sur la fiche d'une Salle sera effective également pour **toutes les Actions de Formations déjà programmées** dans lesquelles elle est utilisée.

Complétez ensuite les autres informations, telles que la ***Capacité maximum***, l'***Accès aux personnes en situation de handicap***, les ***Informations pratiques d'accès*** et autres précisions nécessaires.

![](https://d33v4339jhl8k0.cloudfront.net/docs/assets/59b2fb88042863033a1cb464/images/689461f66381655c7b1d33c7/file-dE7CcyA4hc.png)

**À noter** : vous ne pouvez pas renseigner des horaires d'ouverture/fermeture au niveau des Salles.

Dans la section ***Réglages spécifiques***, vous pouvez cocher la case ***Masquer sur le Catalogue Public***, pour que la salle ne soit plus cliquable et que les visiteurs de votre [Catalogue Public](https://doc.dendreo.com/article/188-introduction-au-catalogue-public) ne puissent pas consulter les détails de votre salle (adresse, capacité, accès PMR, etc).
