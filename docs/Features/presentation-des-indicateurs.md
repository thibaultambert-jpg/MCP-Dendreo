# Présentation des indicateurs

Vous retrouvez les indicateurs de votre compte depuis le menu ***Reporting*** > ***Tableau de bord*** > [***Indicateurs***](https://pro.dendreo.com/redirect/tdb.php).

Ce menu est divisé en deux onglets différents : la vue d'ensemble, et les indicateurs de performance.

![](https://d33v4339jhl8k0.cloudfront.net/docs/assets/59b2fb88042863033a1cb464/images/6abd29a7bd0193dcb268d4da/file-QlayufsqYL.png)

## Indicateurs de la vue d'ensemble

Depuis cette interface, vous pouvez visualiser plusieurs graphiques calculés à partir de vos données :

- ***Stagiaires*** : Dendreo comptabilise les participants **inscrits** aux Actions de Formation **confirmées ou non**, dont la date de début est sur la période sélectionnée ;
- ***Heures-stagiaires*** ***synchrones*** et ***à distance asynchrones*** : Dendreo comptabilise les heures de Formation asynchrones auxquelles les Participants étaient **présents** sur les Formations en e-learning finissant sur la période sélectionnée et qui sont dans des Actions de Formation confirmées (étape) ;
- ***Chiffre d'affaire facturé*** : Dendreo comptabilise les Factures **émises** sur la période sélectionnée.
- ***Chiffre d'affaire prévisionnel*** : Dendreo comptabilise les Actions de Formation **confirmées ou non**, **terminées** ou qui **doivent se terminer** sur la période sélectionnée ;
- ***Résultat opérationnel*** : Dendreo comptabilise les Actions de Formation **confirmées ou non**, **terminées** ou qui **doivent se terminer** sur la période sélectionnée.

![](https://d33v4339jhl8k0.cloudfront.net/docs/assets/59b2fb88042863033a1cb464/images/685423ea0bda0b79f26aae0d/file-9hStuDDn7Y.png)

**Attention** : les années de la légende sont basées sur les années civiles et non comptables.

Pour affiner les indicateurs, sélectionnez des dates spécifiques :

![](https://d33v4339jhl8k0.cloudfront.net/docs/assets/59b2fb88042863033a1cb464/images/6859196aa0827746e27e88de/file-noWQyIXm2B.png)

**À noter** : lorsque vous fermerez l'onglet et reviendrez dessus, c'est l'année en cours qui s'affichera.

Le graphique peut également être affiné grâce aux options ci-dessous :

![](https://d33v4339jhl8k0.cloudfront.net/docs/assets/59b2fb88042863033a1cb464/images/68591998b0b4343f5f2a87bc/file-hkduSTNFGy.png)

Vous pouvez également choisir le type de graphique souhaité :

![](https://d33v4339jhl8k0.cloudfront.net/docs/assets/59b2fb88042863033a1cb464/images/685919af18576038c23fca9b/file-xJFBOLgttG.png)

Exportez si besoin vos données en tableur CSV :

## Indicateurs de performance

Depuis cette interface, vous retrouvez les différents widgets qui étaient auparavant sur votre page d'accueil.

**Heures-stagiaires**

Grâce à ce widget, consultez l'aperçu visuel rapide de vos performances années après années pour chaque mensualité. Vous retrouvez en abscisse les mois de l'année, et en ordonnées le nombre d'heures stagiaires.

![](https://d33v4339jhl8k0.cloudfront.net/docs/assets/59b2fb88042863033a1cb464/images/6abe2824c3e570044c288cf6/file-LZ7JSX5cVF.png)

**À noter** : les widgets d'indicateurs de performance ne sont visibles que par les utilisateurs de type ***administrateur*** ou ***gérant*** afin d'assurer la confidentialité de vos informations et le contrôle de leur partage parmi vos collaborateurs.

**Chiffre d'affaires (€ facturés)**

Ce widget vous permet de voir l'évolution de votre chiffre d'affaires en euros facturés, années après années, si vous capturez votre chiffre d'affaires avec Dendreo. Les années correspondent à vos dates de clôture comptable, paramétrées depuis la [configuration générale](https://pro.dendreo.com/redirect/configuration.php) de votre compte Dendreo.

![](https://d33v4339jhl8k0.cloudfront.net/docs/assets/59b2fb88042863033a1cb464/images/6abe2842528fa6f4b198b00a/file-l3O6UL3Ek0.png)

![](https://d33v4339jhl8k0.cloudfront.net/docs/assets/59b2fb88042863033a1cb464/images/685972d6d6f9557cd47fe789/file-YyKIgFsbV1.png)

Interface de configuration de votre clôture comptable

**Remplissage des Formations (%)**

Dans ce widget, consultez le pourcentage de remplissage de l'ensemble de vos Formations au fil des années.

![](https://d33v4339jhl8k0.cloudfront.net/docs/assets/59b2fb88042863033a1cb464/images/6abe286b7cdaed3f1efa5a9c/file-6DZ2KX91UI.png)

**Résultat opérationnel (€)**

Le résultat opérationnel est calculé en fonction du Budget et des frais de vos Actions de Formations et de vos coûts Formateurs. Il s'agit de la **somme des marges de vos différentes Formations**, hors taxes.

Sont reflétées ici les valeurs budgétaires renseignées dans chacune de vos ADF, recettes et dépenses. Depuis le budget de vos ADF, 3 options sont possibles : les recettes libres, les dépenses, et les dépenses refacturées.

![](https://d33v4339jhl8k0.cloudfront.net/docs/assets/59b2fb88042863033a1cb464/images/6abe28b1535b0034271ded4a/file-onWAHrFy8o.png)

Vous retrouvez aussi le widget de résultat opérationnel mais uniquement pour les ADF [confirmées](https://doc.dendreo.com/article/21-etapes-des-actions-de-formation).

![](https://d33v4339jhl8k0.cloudfront.net/docs/assets/59b2fb88042863033a1cb464/images/6abe29157cdaed3f1efa5a9d/file-kACyXdP8OT.png)

Votre coût Formateur est calculé qu'il s'agisse d'un Formateur externe (coût horaire) ou d'un Formateur salarié avec un coût fixe mensuel que nous assimilons en variable. Vous pouvez renseigner le taux de charges de vos Formateurs salariés dans la [configuration générale](https://pro.dendreo.com/redirect/configuration.php) de votre compte Dendreo.

![](https://d33v4339jhl8k0.cloudfront.net/docs/assets/59b2fb88042863033a1cb464/images/685975a070e0db172b4d68a1/file-MWDZj0fSMb.png)

**Chiffre d'affaires prévisionnel (€)**

Vous retrouvez ici la somme des Budgets des Actions de Formations.

![](https://d33v4339jhl8k0.cloudfront.net/docs/assets/59b2fb88042863033a1cb464/images/6abe28ea3be702ed269e3a9c/file-UDVJjSfRHo.png)

Vous retrouvez aussi le widget de chiffre d'affaire prévisionnel mais uniquement pour les ADF [confirmées](https://doc.dendreo.com/article/21-etapes-des-actions-de-formation).

![](https://d33v4339jhl8k0.cloudfront.net/docs/assets/59b2fb88042863033a1cb464/images/6abe29acc3e570044c288cfc/file-4yI9GIXg1f.png)
