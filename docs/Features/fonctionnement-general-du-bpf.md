# Fonctionnement général du BPF

Pour que Dendreo alimente correctement votre Bilan Pédagogique et Financier, il est indispensable que les membres de votre équipe ayant accès à votre compte Dendreo renseignent correctement les données liées à votre activité d'Organisme de Formation.

Dans cette documentation, nous listons l'ensemble des champs ayant un impact sur votre BPF et pour lesquels nous vous invitons à être vigilant lors de votre utilisation de Dendreo.

Les champs dont le libellé est en **violet** impactent le BPF !

## CRM Formateurs

Lors de la création d'une fiche Formateur, le champ ***Statut*** vous permet de déterminer si le Formateur concerné est **salarié de votre Organisme** (contrat CDD, CDI, bénévole, etc.) ou **prestataire externe**.

Selon le statut sélectionné, Dendreo alimente différemment les informations liées aux Formateurs ayant dispensé vos Actions de Formation dans votre Bilan Pédagogique et Financier.

![](https://d33v4339jhl8k0.cloudfront.net/docs/assets/59b2fb88042863033a1cb464/images/68823a2894ec78384659c9fb/file-OJmxZiaBuc.png)

**À noter** : en cas d'erreur, il est toujours possible de modifier le statut d'un Formateur sur sa fiche CRM. Cependant, si vous modifiez le statut BPF d'un Formateur sur sa fiche CRM après qu'il ait été rattaché à une Action de Formation, il n'y a pas de rétroactivité sur celle-ci. Vous pouvez cependant modifier manuellement son statut directement dans l'Action de Formation concernée.

## Catalogue de Formation

Depuis votre [Catalogue de Formation](https://pro.dendreo.com/redirect/modules), assurez-vous que le champ ***Spécialité BPF*** de vos Modules est correctement complété. Il s'agit des spécialités renseignées sur les fiches des Modules qui composent vos Actions de Formation que Dendreo déclare dans votre Bilan Pédagogique et Financier.

![](https://d33v4339jhl8k0.cloudfront.net/docs/assets/59b2fb88042863033a1cb464/images/69d8c95695c6acf8432eb754/file-iVBAQhRsu5.png)

## Action de Formation

Lors de l'administration de vos Actions de Formation (INTER ou INTRA), plusieurs éléments sont à renseigner pour que Dendreo alimente correctement les données de celles-ci dans votre Bilan Pédagogique et Financier.

Certains de ces éléments peuvent être renseignés dès l'étape de programmation de vos Actions de Formation et/ou pré-remplis automatiquement par Dendreo si vous avez configuré les informations par défaut au préalable.

### **Objectifs**

Le Bilan Pédagogique et Financier prévoit un encadré visant à connaître **l’objectif général des prestations dispensées** (Formations visant un diplôme, Formations visant une certification, Formations visant un CQP, Bilans de compétence, etc.).

Pour chaque Action de Formation à déclarer dans votre Bilan Pédagogique et Financier, il est indispensable de vous assurer que l'objectif de l'Action de Formation soit correctement renseigné. Pour cela, rendez-vous sur la fiche ***Résumé*** de votre Action de Formation.

[![](https://d33v4339jhl8k0.cloudfront.net/docs/assets/59b2fb88042863033a1cb464/images/65b36d4a1280097516451a2a/file-yJ34hTM4FG.png)](https://s3.amazonaws.com/helpscout.net/docs/assets/59b2fb88042863033a1cb464/images/65b36d4a1280097516451a2a/file-yJ34hTM4FG.png)

### **Inclure dans le BPF**

Depuis la page d'édition d'une Action de Formation, en cochant la case ***Inclure dans le BPF***, vous pouvez décider de l'inclure ou non dans votre BPF. Il vous est possible de le définir au moment de la création d'une ADF ou de revenir sur une ADF précédemment créée et de la modifier.

![](https://d33v4339jhl8k0.cloudfront.net/docs/assets/59b2fb88042863033a1cb464/images/68823cc1337db07aa961d7cc/file-DRwIsRiM8r.png)

### **Étapes**

Vous pouvez définir en [configuration](https://pro.dendreo.com/redirect/config_etapes.php) les Étapes de vos Actions de Formation devant figurer dans le BPF en définissant des ADF comme ***confirmées***, ***non confirmées*** ou ***annulées***. **Seules les ADF se trouvant dans des Étapes *confirmées* sont comptées dans le BPF.**

[![](https://d33v4339jhl8k0.cloudfront.net/docs/assets/59b2fb88042863033a1cb464/images/65b369d71280097516451a26/file-JwGbx2BJCV.png)](https://s3.amazonaws.com/helpscout.net/docs/assets/59b2fb88042863033a1cb464/images/65b369d71280097516451a26/file-JwGbx2BJCV.png)

Pour vous assurer que votre Action de Formation se trouve dans une Étape ***confirmée***, rendez-vous sur la fiche ***Résumé*** d'une Action de Formation INTRA ou INTER.

[![](https://d33v4339jhl8k0.cloudfront.net/docs/assets/59b2fb88042863033a1cb464/images/65b36d8352a6af5def3c8d71/file-eo1iyYGNIe.png)](https://s3.amazonaws.com/helpscout.net/docs/assets/59b2fb88042863033a1cb464/images/65b36d8352a6af5def3c8d71/file-eo1iyYGNIe.png)

### **Type de Formation**

Assurez-vous que votre Action de Formation soit bien composée d'un Module de type ***Formation***.

### **Relevé de présence des Participants**

Le Bilan Pédagogique et Financier prévoit que vous déclariez le nombre d'heures de Formation suivies par vos Participants. Il est donc indispensable que le relevé de présence de vos Participants soit **correctement renseigné** pour l'ensemble de vos Actions de Formation.

Pour plus d'informations, consultez notre documentation [**Saisir manuellement le relevé de présence**](https://doc.dendreo.com/article/138-releve-des-presences).

### **Financements**

Certaines parties du BPF ne comptabilisent que les Actions de Formation financées. **Vous devez donc vous assurer qu'un Financement est renseigné pour votre Action de Formation**. Rendez-vous sur la fiche de votre Action de Formation, dans le sous-onglet ***Financement*** et ajoutez-les Financements nécessaires en choisissant le ***type de Financement***. Plusieurs Financements sont possibles pour une Action de Formation.

[![](https://d33v4339jhl8k0.cloudfront.net/docs/assets/59b2fb88042863033a1cb464/images/65b369781280097516451a24/file-Lfrh0Rd2FB.png)](https://s3.amazonaws.com/helpscout.net/docs/assets/59b2fb88042863033a1cb464/images/65b369781280097516451a24/file-Lfrh0Rd2FB.png)

Il est nécessaire de vérifier le statut BPF de vos Participants au moment de la création du Financement.

![](https://d33v4339jhl8k0.cloudfront.net/docs/assets/59b2fb88042863033a1cb464/images/69d8c996437f45b66a6bf0ad/file-So5MjUjIyN.png)

**À noter** : si le statut BPF du Participant est modifié APRÈS la création du Financement, cela n'impacte pas cette Action de Formation dans votre BPF.

Pour corriger un mauvais statut BPF pour un Participant après la création du Financement de l'Action de Formation, faites la modification dans l'onglet ***Financement*** de l'Action de Formation. Cliquez sur l'icône de crayon puis modifiez le statut.

[![](https://d33v4339jhl8k0.cloudfront.net/docs/assets/59b2fb88042863033a1cb464/images/65b36ab9270765339befc65f/file-VyvOCIGxGJ.png)](https://s3.amazonaws.com/helpscout.net/docs/assets/59b2fb88042863033a1cb464/images/65b36ab9270765339befc65f/file-VyvOCIGxGJ.png)

![](https://d33v4339jhl8k0.cloudfront.net/docs/assets/59b2fb88042863033a1cb464/images/69496130e2103b0bbdc26127/file-DRuvIcngqs.png)

Pour plus d'informations, consultez notre documentation [**Alimenter le BPF dans Dendreo**](https://doc.dendreo.com/article/402-comment-salimente-le-bpf-dans-dendreo).
